## 案例一：王可——文科生的 10 天 App 奇迹

| 维度 | 详情 |
|------|------|
| 背景 | 汉语言文学专业，一行代码不会写 |
| 业务 | App 开发（具体品类未披露） |
| AI 工具 | AI 编程工具（疑似 Cursor/Claude Code） |
| 方法 | 根据 AI 工具"5 小时额度"拆分早中晚三轮开发 |
| 成果 | 10 天做出可运行 App |
| 收入 | 未披露 |
| 来源 | 远川研究所 2026.06.26 |

### 可复用的点
- 不会技术 ≠ 不能做产品
- 利用免费额度做时间规划
- 快速验证 > 完美打磨

### 局限/未知
- App 是否上线、是否有用户？
- 后续是否持续维护？
- 10 天快速原型 ≠ 可持续产品

## 案例二：孙韶聪——15 年销售转型 AI 创业者

| 维度 | 详情 |
|------|------|
| 背景 | 39 岁，跨国电气集团 15 年销售 |
| 公司 | 北京韶聪泽明智能科技有限公司 |
| 业务 | 工业电气智能选型与报价辅助工具（Monica 数字员工） |
| AI 工具 | Claude Code 自建系统 |
| 契机 | 2025.08 儿子出生 + GPT-5 发布；2026.03 第一次用 AI 将工作痛点变成解决方案 |
| 投入 | 通宵 28 小时与 AI 对话 |
| 成果 | 产品打磨中，有明确意向但无收入 |
| 现状 | 创业三个月，靠自有资金维持 |

### 可复用的点
- 行业认知是最大壁垒——他知道工业电气选型有多痛
- 从自己的痛点出发，不是追逐热点
- 养成"生活中遇到任何事都下意识问 AI"的习惯

### 局限/未知
- 目标客户（工业电气）决策链条长
- ToB 销售周期长，一人公司能否支撑？

## 案例三：赵争明——用 AI 开卤肉饭店

| 维度 | 详情 |
|------|------|
| 背景 | 没念完初中，从未去过台湾 |
| 业务 | 台湾卤肉饭堂食店 |
| AI 工具 | 自学 AI（具体工具未详述） |
| 方法 | AI 辅助选址、装修、菜单设计、海报生成、毛利测算 |
| 投入 | 4 万多元 |
| 成果 | 开业第一个月回本 |

### 可复用的点
- AI 全链路嵌入实体经营
- 极低启动成本
- 实体店有自然流量，不需要纯线上获客能力

### 局限/未知
- 首月回本是否稳定持续？
- 一人经营实体店的精力天花板

## 案例共性提炼

### 成功者共性
1. **从自己的真实痛点出发**，不是追热点
2. **快速验证**，不追求完美
3. **把 AI 当成协作伙伴**，不是玩具
4. **极低的启动成本**，不赌身家

### 挣扎者共性
1. 不知道如何把业务数据喂给 AI
2. 担心成本，倾向只用免费工具
3. 场景非标准，通用 AI 不好用
4. 缺乏持续动力（没有团队氛围）

### 关键分水岭
> 行业认知 × AI 能力 = 壁垒
> 只靠 AI 能力 = 随时被替代

## 案例写作指导

1. 每个案例用三段式：背景 → 做法 → 结果
2. 不要只写成功，要写"还没成功"
3. 标注数据来源和时间
4. 给读者一个"如果是我能不能做到"的自测问题
5. 避免英雄叙事，强调"他们也是普通人"
