# scene_ocp · 一人公司 OCP 系列

## 系列定位

> **面向人群**：想用 AI 一个人干一个团队的事、正在探索或已经踏上"一人公司"之路的职场人、自由职业者、小创业者。

这不是一套"一人公司创业教程"，而是一个**真实观察 + 实操指南 + 自我剖析**的混合体。

我们自己就是这个命题的活样本——一个用 AI 写文章、做排版、管知识库的个体项目，本质上就是一人公司的雏形。

## 为什么现在写这个？

- **2025 年日均新增 1.57 万家一人公司**，2026 年势头不减
- **97.4% 的小微经营者听说过 AI**，57% 每天与 AI 协作超 8 小时
- **1 元 AI 成本 ≈ 72 元开发人力**，成本结构被彻底改写
- 全国 **OPC 社区超 426 个**，政府真金白银扶持（北京最高 200 万、杭州 10 亿专项基金）

但残酷的另一面：
- **92.4% 的 OPC 仍处于筹备或早期阶段，未盈利**
- 大部分人和"众包骑手"没区别——用 AI 提高效率后卖劳动成果
- **AI 降低了"做出来"的门槛，没降低"活下去"的门槛**

## 核心命题

> **一个人 + AI，到底能不能成？如果能，成的是什么？**

## 内容原则

1. **不用二手信息**：数据来自一手访谈、研究报告、亲身体验
2. **不只讲成功，更讲失败**：避坑比模仿更重要
3. **不自嗨**：承认自己也在路上，不包装成导师
4. **与项目其他系列联动**：工具链部分自然衔接 CodeBuddy、RAG、Claude Code 系列
