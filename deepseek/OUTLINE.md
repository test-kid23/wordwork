### 2.1 结构换代：V4.1 Flash 为什么"小模型打赢了自家旗舰" ✅
- 成文：`2.1-deepseek-v4-1-flash-architecture.md` + `-wx.html`
- 发布标题：《552B 的模型只开 8B 干活：DeepSeek 把"大力出奇迹"反过来用了一次》
- 实际结构：三个反常 → 8B 进 16B 出 → 缓存压到 1/4 → 多模态并进主模型 → 成绩单怎么读 → 迁移三个动作 → 先别动的地方
- 定位：9 月 10 日的发布会没人开，但它是 V4 之后最重要的一次架构变更
- 核心叙事：不是"又一个更强的模型"，而是**换了一套模型结构**——Causal-Encoder-Decoder，输入 8B / 输出 16B 的非对称激活
- 必讲三段因果：
  1. 非对称结构 → 同等智能下激活更少 → 单 token 成本更低
  2. KV Cache 压到上一代 1/4（HBM）、1/8（SSD），累计缩 437 倍 → **Agent 长会话的缓存命中费才是真正的成本大头**
  3. 原生多模态并入主模型 → 不用再单独挂 vision 模型，读图 / 读截图 / 读图表就是一个调用
- 成绩单怎么读：GPQA 90.9、Codeforces 3471、Terminal-Bench 2.1 90.6、DeepSWE v1.1 74.2、HLE 36.8（带工具 63.9）——哪些是真进步、哪些是换了测试框架
- 迁移实操：模型名从 `deepseek-v4-flash` 改成 `deepseek-flash`；旧名仍可用但底层已换；V4 Flash Vision Exp 已下线
- 一段小插曲：9/9 说 9/14 起把 V4 Pro 请求全路由到 V4.1 Flash 并按 Flash 计费 → 9/10 推迟下线 → 9/11 宣布"继续提供 V4 Pro，计费不变"。**这条时间线是判断 DeepSeek 产品节奏的好样本**
- 价格对照：8/17 那版 vs 9/10 现行版，省了多少（用真实用量算）
- ⚠️ 提醒读者：本文发布时 `deepseek-v4-pro` 仍在，但已不是性价比首选

### 2.3 1017：分数更高，反而更便宜 ✅
- 成文：`2.3-deepseek-v4-1-flash-1017-cost.md` + `-wx.html`
- 发布标题：《同一个模型名、同一个价签：5 周它涨了 35%，单任务成本却砍掉六成》
- 实际结构：三个数字 → 成绩单（11 项对比，涨最狠是"动手类"）→ 输出变短为何是大新闻（单任务成本官方图读数 $0.5→$0.2，标注可信度中等）→ 耗时变短的 Agent 意义 → 视觉涨一轮 → 点名三框架的深意 → 换不换三张表 → 三个别当真
- 定位：10 月 17 日的小版本，官方叫"帕累托改进"，实际是"涨分 + 降本"同时发生
- 两组数字对着看（本篇骨架）：
  - 涨分：DeepSWE v1.1 74.2 → 77.0；Terminal-Bench 4.0 31.2 → 42.3（+35%）；ProgramBench 20.3 → 29.1；Automation-Bench 54.8 → 60.5
  - 降本：任务运行时间缩短 + 输出长度减少 → 单次任务综合成本下降
- 为什么"输出更短"是大新闻：Agent 场景里输出 token 占账单大头，话变少等于钱变少（配一张"同一任务改版前后 token 对比"的自测表）
- 横向位置：同档对比 Claude Opus 5、GPT-5.6-sol、Kimi K3、GLM 5.3，四项 Agent 基准领先——**但要说清测试框架差异，不做无脑吹**
- 平台联动：官方明确针对 DeepSeek Harness、腾讯 CodeBuddy、WorkBuddy 做了框架级优化，Harness 需升到 ≥ 0.2.1-rc.1
- 自测：同一批任务在 9/10 版和 1017 版上的耗时 / token / 花费三列对比
- 顺手领的福利：符合条件的用户首次登录 Harness 可领 6 元赠金（无需充值，7 天有效，限量）——**写法上要标"活动规则以官方为准、可能变化"**
- 结论：如果手上只有一次"要不要换模型"的判断机会，1017 是当前默认答案

- 成文：`2.4-deepseek-wish-driven-programming.md` + `-wx.html`
- 发布标题：《160 个字的提示词，6 分钟，2739 行代码：许愿式编程许的是什么愿》
- 实际结构：三档定义 → 官方四案例各证什么 → 三个公开实测样本（160 字→78KB 单文件赛车 / 开封+赛车约 6 元 / 铁塔与剪纸的正反课）→ 为什么能做到（自反馈 RL + 可自检题材）→ 许愿姿势模板 → 七个翻车点 → 六条验收红线 → 该许与别许清单
- 定位：官方四个案例（故宫 3D 建模、网页赛车游戏、Godot 复刻《传送门2》、Valley of Ages）背后是"基于自反馈的 RL 训练"，重点是**从零构建完整项目**，不是补全代码
- 概念拆解：什么叫"许愿式"——少提示词、少轮次、不写规格文档，让模型自己规划 → 写 → 跑 → 看结果 → 自己改
- 实操主线（本篇必须自己跑）：在 Harness 桌面端用一段话做出一个小游戏 / 一个 3D 展示页，全程记录轮次、耗时、花费、翻车点
- 四段式结构：愿望 → 它自己拆了什么 → 中间崩在哪 → 最后交付什么样
- 能做什么 / 做不到什么：
  - 能做：单页应用、小游戏、可视化、静态 3D 展示、数据处理脚本
  - 难做：需要账号体系 / 支付 / 真实后端状态的项目；依赖特殊环境与素材的项目；需要审美判断的成品级 UI
- 验收红线：能跑起来 ≠ 能用；要检查依赖是否锁版本、是否有硬编码密钥、是否只在它自己的环境里跑得通
- 成本账：这类"许愿"任务一次多少钱（附真实账单）

### 2.5 Search / Fetch：DeepSeek 把自己的搜索引擎开放了 ✅
- 成文：`2.5-deepseek-search-fetch-api.md` + `-wx.html`
- 发布标题：《7 个动作压成 2 个：DeepSeek 把自研搜索引擎做成了 API，千次 5 块钱》
- 实际结构：卖的是"给模型看的搜索结果" → 跑通最小例（curl/Python）→ 五个参数（query 128 字符坑、need_content 分两步）→ 返回字段（rerank_score≥1.5、authority≥3、snippet vs summary）→ 搜索语法（site:/lang:/after:/before:）→ 7 步变 2 步的三个落地场景 → 计费账（5 元/千次、100/25 QPS、11/1 生效）→ 错误码与重试
- ⚠️ 关键校正：官方文档限速为 **Search 100 QPS / Fetch 25 QPS**（账号级、独立计算，Fetch 另有域名级限速）；社群早期流传的 5 QPS 是上线初期口径，已过时
- 定位：10 月 17 日最有商业含义的一条——模型厂开始卖"信息层"
- 接口速览：`POST /v1/tools/search`、`POST /v1/tools/fetch`，与主 API 共用 Key 和 Base URL，零迁移成本
- 参数逐个讲（照文档抄，别自己编）：`query` 1—128 字符、`count` 默认 10 最多 50、`ori_question` 帮理解意图、`localization` 本地化、`need_content` 是否带全文；Fetch 直接回 Markdown
- 计费与限制：5 元 / 千次**成功**请求，失败与空结果不计费；5 QPS（端点独立）；**11 月 1 日 00:00 起计费**
- 窗口期提醒：现在在 Harness / Claude Code / Codex 里通过服务端工具调用走的 Search、Fetch 还不收钱，11 月 1 日之后开始计
- 为什么值得写：过去给 Agent 接联网要 7 个动作（选源、谈额度、写解析、反爬、清洗、去重、接模型），现在 3 个动作
- 实操一：给本地 Agent 接联网检索，把"查一下"变成一次工具调用
- 实操二：竞品资料汇总——Search 找候选页 → Fetch 抓正文 → 模型总结，全程不写解析器
- 实操三：RAG 的实时兜底——本地知识库没命中时回落 Search（附判断逻辑）
- 边界：受目标站点访问策略影响、不保证覆盖、比自建贵还是便宜要按场景算（写清"什么量级下自建更划算"）
- 与 Kimi / 其他搜索 API 的横向：单价、返回结构、是否需要单独申请

### 2.6 一个月的另一半故事：宕机补偿与 V4.1 Pro 之谜
- 定位：给 9—10 月这段做一个"冷静"的收尾，也是系列里少见的"方法论"篇
- 宕机复盘：10/15 08:11—13:04 近 5 小时，网页 / APP / API 全挂；官方"剥离单点依赖"的承诺意味着什么（对重度依赖方 = 必须自建降级方案）

- 我们的应对清单：多供应商兜底、请求超时与重试、非关键任务降级到 Flash、把定时任务错峰

## 写作原则（沿用 wordwork 体系）

1. **不追热点，建体系** — 蹭的是热度，建的是 DeepSeek Agent 工作流的知识体系
2. **可操作，不空谈** — 每篇都有能跑起来的命令、参数和配置

6. **截图优先** — 教程类文章必须有真实界面截图（Harness 桌面端 / 后台 / 终端输出），占位符先标后用
7. **不用"你"称呼** — 统一用"我 / 我们 / 大家"视角
