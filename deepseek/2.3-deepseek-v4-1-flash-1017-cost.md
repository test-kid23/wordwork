# 同一个模型名、同一个价签：5 周它涨了 35%，单任务成本却砍掉六成

> V4.1-Flash-1017 实测——涨分不稀奇，稀奇的是输出变短、耗时变短，钱还跟着少。

---

## 写在前面

模型升级的标准剧本是：分数涨一点，账单涨一截。想让 Agent 干得更好，就得接受它多想一会儿、多跑几步、多吐 token——这条规律在过去两年基本没被打破过。

十月这次，DeepSeek 把这条规律掰了一下。官方给的定性叫"性能—费用的帕累托改进"：基准全面抬升的同时，**任务运行时间缩短、输出长度下降**，单次调用的综合成本不升反降。

这句话如果成立，它的意义比涨几个点大得多。因为对天天跑 Agent 的人来说，贵从来不是贵在"每百万 token 多少钱"，而是贵在"这个任务它跑了多少轮、吐了多少字"。

这篇把 1017 这版的账算清楚：分数涨在哪、成本降在哪、哪些平台吃到了专门优化、以及哪三个地方不能全信。

## 一、三个数字，一句话说完

- **分数涨了**：DeepSWE v1.1 从 74.2 到 77.0，Terminal-Bench 4.0 从 31.2 到 42.3；
- **成本降了**：官方放出的 DeepSWE 单任务成本图显示，同一个任务的花费从约 0.5 美元降到不足 0.2 美元；
- **价签没动**：还是 `deepseek-flash` 这个名字，还是九月那版价格，调用代码一行都不用改。

三个数字放在一起就是这次更新的全部要点：**能力往上走，账单往下走，接口原地不动。**

顺带一提时间跨度：九月十日发布 V4.1 Flash，十月十七日推出 1017，中间只隔了五周。五周时间把终端操作类基准抬了 35%，这在新架构的第一代产品上并不常见——通常这种涨幅要等一次完整换代。

看这张表有个反直觉的地方：**涨得最多的是"动手类"基准，不是"知识类"基准。**

Terminal-Bench 4.0 涨 11.1 分，ProgramBench（程序逆向）涨 8.8 分，Apex Bench（多模态 Agent）涨 7.5 分。而衡量纯知识推理的 HLE 涨了 5.8 分，已经算不错，但仍不如动手类。

这指向一个明确的方向：**这一版花力气的地方是"把事做完"，不是"把题答对"。**

媒体在横向对比时给了两组说法：1017 在九项测试上高于 GPT-5.6-Sol；与 Claude Opus 5 相比，在 DeepSWE、Automation-Bench、Agents' Last Exam、Apex Bench 四项上领先。DeepSWE 那一项的具体数字是 77.0 对 74.0。

这里要说明一句：**这些分数都是官方自己跑的，第三方独立复现还没出来。** 当参考可以，当采购依据不行——原因在第八节展开。

## 三、输出变短，为什么是大新闻

如果一个模型"变聪明"的方式是多想一会儿、多写一段，那它对 Agent 场景其实是负担——因为 Agent 的每一次工具调用都要重新吐一轮 token，轮数一多，账单是指数级的。

所以官方那句"缩短了任务运行时间与输出长度"，值得逐词拆开看。

**先说输出长度。**

在按 token 计费的世界里，输出是最贵的一档。按现行价格，`deepseek-flash` 空闲时段输入（未命中缓存）1 元 / 百万 token，输出 4 元 / 百万 token，**输出是输入的 4 倍**。这意味着：同样一个任务，输出少两成，总花费可能降三成以上。

**再说单任务成本。**

官方新闻页放了一张"DeepSWE v1.1 Pass@1 对比单任务成本"的图，注明使用 mini-swe-v2 框架测试。图里读出来的大概是这样：

| 指标 | 九月版 | 1017 |
|------|--------|------|
| DeepSWE v1.1 Pass@1 | 74.2 | 77.0 |
| 单任务成本（官方图读数） | 约 0.5 美元 | 不足 0.2 美元 |

社区按图换算成人民币，给出的说法是"max 档通过率约 77%、单任务约 1.3 元，上一版 74.2% 对应约 3.3 元"。

**这两组数字要打个标签：来自官方图表的读数，不是官方文字结论，可信度中等。** 方向可信（成本确实降了），具体数值请以自己的实测为准。这一点我会在文末再强调一次。

## 四、耗时变短，对 Agent 意味着什么

输出变短，顺带带来第二个变化：任务跑得更快。

单看一次调用，快几秒没什么感觉。但 Agent 是串行执行的——一个改 Bug 的任务跑二十轮，每轮省十几秒，整体就是几分钟的差距。对交互式使用，这个差别很实在：从"等它想"变成"等它做完"。

真实的体感样本可以看社区那次记录：升级到 Harness 0.2.1-rc.2 之后，给一段约 160 字的提示词，19:05:56 开跑，19:11:42 写出文件——**不到 6 分钟**，产出一个 78KB、2739 行、零外部依赖的单文件网页赛车游戏。这个案例在下一篇会细讲，这里只用它的时间维度做参照。

不过也得说清另一面：**快的是"小到中等规模的任务"。** 涉及多文件、多依赖、需要反复调试的项目，时间仍然以小时计。把"6 分钟做个赛车游戏"当成"所有开发都变 6 分钟"，是这类宣传最常见的误读。

## 五、视觉能力顺便涨了一轮

这次官方成绩单里还有一组容易漏掉的数据：

- Chartography（图表解析，带工具）**83.0**；
- BabyVision（带工具）**92.5**；
- ZeroBench-main（带工具，Pass@5）**51.0**。

三项都是"看图"类。考虑到 `deepseek-flash` 是当前唯一支持图像理解的模型（`deepseek-v4-pro` 不支持），这组提升的实际意义是：**报错截图、数据报表、UI 设计图，可以直接丢进去换成代码或结论。**

日常用法里最省事的三个动作：

1. 报错截图 → 让它读堆栈、定位问题；
2. 一张数据表截图 → 让它转成结构化表格或写分析；
3. 一张设计图 → 让它出对应的页面结构。

**边界也要说清**：图表解析强，不等于排版精度高。像素级还原、字体字号、间距这些，仍然要人调。

## 六、点名三个框架，这件事值得琢磨

官方公告里有一句话很容易被跳过：本次**着重针对 DeepSeek Harness、腾讯 CodeBuddy、WorkBuddy 等平台框架做了优化**，并要求 Harness 升级到 0.2.1-rc.1 及以上版本。

这句话的分量在于：**模型厂开始为"具体的壳"调模型了。**

过去模型和工具是松耦合的——模型给 API，工具自己适配。现在顺序反过来了：先确定几个主流 Agent 框架，再针对它们的工具调用习惯、上下文组织方式做训练侧优化。这意味着两件事：

- **同一个模型，在不同框架里的表现会有可见差距**，而且这个差距是官方刻意拉开的；
- **升级框架不再是"可选优化"，而是拿到模型全部能力的前提**。Harness 不升到 0.2.1-rc.1，吃的就是上一代的适配水平。

对使用方的行动项很直接：如果主战场是这三个框架之一，升级顺序应该是**先升框架，再压测模型**，别反过来。

## 七、换不换：三张判断表

**该换的：**

- **Agent 密集的活**：改代码、跑测试、批量文件处理——这次涨的就是这块；
- **要读图的活**：截图、报表、设计稿，Flash 是唯一选项；
- **批量任务**：单任务成本降幅比分数涨幅更值钱，量越大越明显。

**不用急的：**

- 已经跑得很稳、对行为一致性要求高于成本的核心链路；
- 只在固定模板下做文本生成的场景（涨幅感知不到）；
- 依赖 V4 Pro 特定行为的存量业务（Pro 仍可用，别在这时候折腾）。

**怎么换：**

代码层面零改动——模型名还是 `deepseek-flash`，价格表也没变。要动的是三件事：**升级 Harness 到 0.2.1-rc.1 以上**、**重跑一遍自己的任务集对比成本**、**把"输出变短"纳入 prompt 设计**（既然它更倾向于简洁，就别再要求它"详细展开每一步"，否则白费这个优化）。

顺手还能拿的一点福利：符合条件的用户首次登录 Harness 可领 6 元赠金，无需充值、7 天内有效、限量发放。规则以官方页面为准，别当长期政策。

## 八、把话说全：三个别当真的地方

**① 官方分数 ≠ 我们的中位数。**

官方演示证明的是"上限存在"，不是"平均能到这"。同一批任务，换到自己的需求集上，掉 20 分是常态。想判断值不值得换，唯一的办法是拿自己的十个真实任务跑一遍，看完成率、耗时、花费三列。

**② 图表读数 ≠ 官方结论。**

前面那个"0.5 美元降到 0.2 美元"，是从官方图表里读出来的，不是官方文字写的。读数会有误差，把"约 1.3 元"当精确值去算预算，容易翻车。

**③ 第三方复现还没出来。**

截至这篇成稿，这些成绩都是官方口径，独立第三方复现尚未公布。这不是说数字有问题，而是提醒一句：**新模型上线头两周，社区热度会放大一切**，等两周看稳定反馈更划算。

## 写在最后

这次更新最值得记的不是某一行分数，而是它打破的那个默认假设：**让 AI 干得更好，未必要花更多钱。**

过去两年，性能与成本的曲线是斜着往上的——想往上走，就得往右走。1017 这版把这根曲线往回掰了一点：输出更短、耗时更短、分数更高、价签不动。

掰得不多，但方向变了。对天天跑 Agent 的人来说，方向比幅度重要——因为它意味着下一轮迭代还能继续往这个方向走。

不过分数和账单都只是前半场。真正让人坐直的是这一版主推的那个能力：**只给一句话，它自己把项目从零做出来。** 下一篇就讲这个——四个官方案例、三个公开实测，以及它一定会翻车的地方。
