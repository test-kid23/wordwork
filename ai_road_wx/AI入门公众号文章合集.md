## 先搞懂：API Key 到底是个啥？

用大白话讲，API Key 就是你调用大模型能力的 “门票”。

之前咱们用聊天工具，是人家已经把大模型包装好了，给你一个聊天界面，你只能在人家的界面里用。但有了 API Key，你就可以直接把大模型的能力，接到你自己的工具、自己的流程里，比如接到你的公众号、你的淘宝后台、你的邮箱里，让它自动帮你干活。

简单说，就是把 AI 变成你自己的员工，给它安排工作，不用你手动跟它聊天了。

## 第一步：怎么拿到 DeepSeek 的 API Key？

DeepSeek 最近真的太火了，能力强还便宜，国内的不用翻墙，新用户还有免费额度，咱们就以它为例，教大家怎么拿 Key。

1. 首先打开 DeepSeek 的 API 平台：[platform\.deepseek\.com](https://platform.deepseek.com/)，用手机号注册个账号，登录进去。

2. 登录之后，左边的菜单栏里找到「API Keys」，点进去。

![Image](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/authcode/?code=YjgxZjRiNGY3MmM3ZDlkY2QzNTY1YWQ4MTdkYTUzOTFfNjc4Y2JkYmY0YThhZjQxYzNhN2E4YjI4MTRkYTc3YWNfSUQ6NzY1MDAyNjU3MTQ5NjE2NDU1N18xNzgxMTYxNTQxOjE3ODEyNDc5NDFfVjM)

3. 然后点「创建新 API Key」，给它起个名字，比如 “我的小工具”，点创建就好了。

⚠️ 重点提醒！这个 Key 创建完之后，只会显示这一次！你一定要立刻复制下来，存到你的记事本里，要是丢了，就找不回来了，只能重新创建一个。还有，这个 Key 千万别随便给别人，也别传到网上，不然别人拿到就能用你的额度花钱了！

## 要是想学点简单的，也能试试几行代码调用

要是你稍微懂一点 Python，那调用 API 就更简单了，就这么几行代码，复制粘贴改改就能用：

```python
import requests

# 你的API Key，把刚才复制的填进去
api_key = "sk-xxxxxxxxxxxxxxxxxxxxxxxx"

url = "https://api.deepseek.com/chat/completions"
headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json"
}
# 你要问的问题
data = {
    "model": "deepseek-chat",
    "messages": [{"role": "user", "content": "帮我写一个夏天卖冰粉的朋友圈文案"}]
}

response = requests.post(url, json=data)
print(response.json()['choices'][0]['message']['content'])
```

就这么简单，运行一下，它就直接把文案给你输出了，你可以把它加到你自己的小脚本里，比如自动处理数据、自动发消息，都可以。

## 国外篇：能力强，但需要翻墙

### 1\. OpenAI Codex（GitHub Copilot）

这个就是最早的 AI 代码工具了，很多人应该都听过。

- 怎么用：主要是装成编辑器的插件，比如 VS Code 的 Copilot 插件，需要订阅，每月大概 10 刀。

- 它能帮你做什么？

    - 实时补全代码，你写一半，它就帮你写完了，比如你写个注释 “\# 读取这个文件夹里的所有 TXT 文件，合并成一个”，它直接就把对应的代码给你生成了。

    - 支持几乎所有的编程语言，不管你是写 Python、Java 还是前端，它都能帮你。

- ⚠️ 注意：需要科学上网才能用，而且要付费订阅。

---

## 最后说两句

其实这些工具，真的不是只有程序员才能用，就算你一行代码都不会写，也能用它们帮你解决好多问题：

- 你想整个批量处理文件的小工具，不用找别人，自己跟 AI 说一声，它就给你做了。

- 你看不懂网上的代码，让 AI 给你翻译成大白话。

- 你想整个自己的小网站，不用找外包，花几十分钟，AI 就帮你搞定了。

现在的 AI，真的把编程的门槛降得特别低，就算你不是程序员，也能用上这些工具，帮自己省时间，搞定那些之前搞不定的小需求，真的可以试试。
