1 第一扇门：Hermes —— 让 AI 像团队一样协作

📌 它是什么？

Hermes 是一个智能 Agent 框架。它的核心理念是：把大任务拆给多个 AI Agent，各司其职，自动协作。

📌 举个例子你就懂了

你想要一篇公众号文章，从选题到发布全自动。传统做法是你在聊天框里一步步引导。用 Hermes + API Key：

选题 Agent（分析热点）→ 写作 Agent（生成初稿）
　→ 校对 Agent（检查错别字和事实）→ 配图 Agent（生成封面）
　→ 发布 Agent（定时推送）

你只需要给一个目标，Hermes 自动调度各个 Agent 依次工作。每个 Agent 背后都通过 API Key 调用大模型能力。

📌 API Key 在这里的价值

▸ 一个 Key 驱动多个 Agent：不像聊天工具只能一对一，Agent 框架让你同时派出多个"AI 员工"。

▸ 自动化流水线：设好流程，它可以每天定时跑，你完全不用管。

▸ 可扩展：除了 DeepSeek，你还可以接入其他模型的 Key，不同任务用不同模型。

📌 适合场景

▸ 内容生产：选题 → 写作 → 校对 → 配图 → 发布
▸ 数据分析：采集 → 清洗 → 分析 → 可视化 → 报告
▸ 客服自动化：意图识别 → FAQ 匹配 → 人工转接
▸ 代码开发：需求分析 → 写代码 → 跑测试 → 修 bug

📌 适合谁？

想搭建自己 AI 工作流的进阶用户；日常有重复性内容生产需求的人（运营、自媒体、电商）；想尝试"多 AI 协作"玩法的探索者。

2 第二扇门：Claude Code —— AI 住进你的终端，帮你写代码

📌 它是什么？

Claude Code 是 Anthropic 推出的终端 AI 编程助手。把它装到你的命令行里，一句自然语言描述，它就能读代码、写代码、改 bug、跑测试、甚至管理 Git。

📌 跟 CodeBuddy / MarsCode 有什么不同？

▸ CodeBuddy / MarsCode：网页/IDE 内的辅助工具，你说需求它出代码。你问 → 它答 → 你复制运行
▸ Hermes：Agent 框架，管"模型们怎么协作"。编排 → 自动执行
▸ OpenClaw：本地优先个人 AI 助手，管"多渠道收件 + Agent 执行"。多渠道接入 → Gateway 调度 → 自动执行
▸ Claude Code：终端内 AI 程序员，AI 直接操作代码。你描述 → AI 直接读写文件、跑命令

Claude Code 最大的不同：它不是"给你建议"，而是直接动手。它可以读写你的项目文件、执行终端命令、管理 Git，像一个真正的程序员同事。

📌 API Key 怎么接入？

Claude Code 使用 Anthropic 的 API Key，配置方式很简单：

# 在终端设置环境变量
export ANTHROPIC_API_KEY="sk-ant-xxxxxxxxxxxxxxxxxxxxx"

# 然后启动 Claude Code
claude

也可以接入其他兼容的 API（如通过 OpenClaw 转发），用你已有的 DeepSeek 或其他模型的 Key。

📸 Claude Code 终端界面截图：用中文描述需求，AI 自动写代码

📌 它最擅长的三件事

① 接手陌生项目
给它一个 GitHub 仓库，它自动分析架构、画出模块关系、帮你快速理解。

② 从需求到上线一条龙
你说"帮我加一个用户登录功能"，它写代码 + 写测试 + 跑通，你只负责 review。

③ 代码审查
把你的改动丢给它，"帮我 review 这次提交，检查安全问题"。

📌 适合谁？

有编程基础的开发者（需要会用终端和 Git）；想大幅提效的程序员；想学编程，让 AI 当一对一导师的人。

3 第三扇门：OpenClaw —— 本地优先的个人 AI 助手（小龙虾 🦞）

📌 它是什么？

OpenClaw（昵称"小龙虾 🦞"）是一个本地优先的个人 AI 助手平台，跑在你自己的设备上，通过你已经在用的聊天工具来交互——微信、QQ、Telegram、WhatsApp、Slack、Discord 等 26+ 平台全覆盖。GitHub 379k+ Stars，TypeScript 构建。

它不只是聊天：支持语音唤醒、实时 Canvas 画布、多智能体路由、Cron 定时任务，像一个长住在你所有设备里的 AI 管家，随时随地听你指挥、帮你干活。

📌 为什么需要它？

▸ 数据主权：跑在自己的设备上，数据不出门，没人能偷看你的聊天记录。

▸ 全渠道覆盖：26+ 消息平台统一收件箱，在微信上指挥它，在 Telegram 上也能收到结果。

▸ 多智能体路由：工作群和私人聊天可以分别派给不同的 Agent，互不干扰。

▸ 语音 + 画布：开车时说句话就能让 AI 干活；让 AI 画个看板，手机秒变屏幕。

▸ Skills 技能系统：ClawHub 社区共享技能，想让它会什么就装什么。

📌 API Key 在这里怎么用？

OpenClaw 本身是助手平台，不绑定模型。你在 Gateway 配置里接入任意模型的 API Key——云端用 DeepSeek/Claude/GPT 的 Key，本地用 Ollama 跑开源模型，还支持故障自动切换备用模型。一套助手，模型随便换。

💡 跟前面两个的区别：Hermes 管"多个 Agent 怎么编排协作"，Claude Code 管"终端里 AI 帮你写代码"，OpenClaw 管"你的个人 AI 助手怎么融入日常生活"——它是你所有设备和聊天工具背后的那只看不见的小龙虾 🦞。

📌 适合谁？

想让 AI 真正融入日常，而不是每次打开网页问两句的人；需要跨设备、跨平台，一个助手管所有消息渠道的人；想有完全数据主权，不希望聊天记录存在别人服务器上的人。
