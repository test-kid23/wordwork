🎯 三句话记住整个系列

① 分岗分工，各司其职
别让一个 AI 同时当主编、主笔、设计、运营——每个角色有且只有一份职责。

② 人在关键节点，不在每个节点
你的价值是判断、审美、风险决策。AI 替你跑流程，你替 AI 把关。

③ 搭完只是开始，迭代才有复利
Prompt 会老化，模型会升级，你的能力会进步。不迭代的 AI 团队不会自己变好。

1 四步法：今晚就能开搭

✉️ 第一步：拆岗位（10 分钟）

拿一张纸，写下你上周做的所有工作。不是抽象概括，是具体动作：

✅ 好的拆分：
每天早上花 20 分钟找选题、看竞品 → 「选题/策略岗」
写一篇文章 2 小时 → 「内容写作岗」
做封面图 30 分钟 → 「视觉设计岗」
改写成小红书、知乎版 20 分钟 → 「渠道分发岗」
看后台数据 10 分钟 → 「数据分析岗」

❌ 不好的拆分：
"内容创作"（太笼统，没法对应具体 Agent）

交付物：一张表，左边是任务，右边是岗位名。

✉️ 第二步：匹配工具（5 分钟）

📊 选题/策略 — Claude Sonnet API
💰 ¥80-150/月

📝 内容写作 — Claude Sonnet API（或 DeepSeek 省钱版）
💰 ¥10-150/月

🎨 视觉设计 — AI 绘图（如 Midjourney、DALL·E）
💰 ¥70-150/月

📢 渠道分发 — Claude Haiku API（够用，便宜）
💰 ¥20-40/月

💻 编程开发 — Cursor / Ollama本地 + Qwen3-Coder
💰 ¥150 或 ¥0/月

📊 客户方案 — Claude Sonnet + Gamma
💰 ¥80-150/月

💡 省钱提示：先用 DeepSeek API 替 Claude 做写作（成本 1/10），等产出稳定了再切 Claude 提质量。

✉️ 第三步：串起第一个工作流（30 分钟）

不要一口气把 6 个 Agent 全串起来。先串 2 个：

① 注册 Make.com（免费额度够用）

② 创建第一个 Scenario：手动 Webhook → 调 Claude API（选题）→ 返回结果

③ 跑通后加第二个节点：选题确认 → 自动推送给写作 Agent

④ 先跑 3 天，没问题了再加设计 Agent 和渠道 Agent

💡 关键原则：不是一步到位，是每一步都确认跑通了再往下。搭工作流最浪费时间的事——一口气全搭好，然后 Debug 三天找不到哪一环断了。

✉️ 第四步：沉淀（持续做）

📅 本周

把你现在用的 3 个最好用的 Prompt 存到一个文件里
文件名：ai-prompts-2026-06.md，存到你觉得不会丢的地方

📅 本月

部署 Dify 社区版（Docker 一行命令，30 分钟）
把你最好的 10 篇历史文章放进知识库
让写作 Agent 在写稿前先检索你的往期文章

📅 下个月

看一眼 API 账单，简单任务的模型换成便宜货
翻一遍 Prompt 历史，删掉改完没效果的改动
问自己：有没有 Agent 从来没用过？删掉它

最后说一句

真正的差距不在"用不用 AI"，而在你怎么组织 AI。

🔹 青铜玩家
零散用各种工具，人困在工具之间搬运。

🔹 白银玩家
深度用一两个 AI，能榨出高质量输出。

🔹 黄金玩家
把 AI 当团队管——Agent 各司其职、自动协作、持续迭代。人的精力从"干活"转移到"管方向"。

从"用工具"到"建团队"，这个认知差就是机会。它在，但不会太久。
