## 先搞懂：API Key 到底是个啥？

用大白话讲：**API Key = 你调用大模型能力的"数字钥匙"。**

之前用聊天工具，是厂商把模型包好，给你一个固定的聊天界面。有了 API Key，你就可以把大模型的能力**接到任何地方**——终端、脚本、自动化工具、甚至你自己搭的 Agent。

简单一句话：**聊天工具是"你去它家做客"，API Key 是"你把它请回来打工"。**

## 第一扇门：Hermes —— 让 AI 像团队一样协作
![alt text](image/Hermes.png)

### 它是什么？

Hermes 是一个智能 Agent 框架。它的核心理念是：**把大任务拆给多个 AI Agent，各司其职，自动协作。**

### 举个例子你就懂了

你想要一篇公众号文章，从选题到发布全自动。传统做法是你在聊天框里一步步引导。用 Hermes + API Key：

```
选题 Agent（分析热点）→ 写作 Agent（生成初稿）
    → 校对 Agent（检查错别字和事实）→ 配图 Agent（生成封面）
    → 发布 Agent（定时推送）
```

你只需要给一个目标，Hermes 自动调度各个 Agent 依次工作。每个 Agent 背后都通过 API Key 调用大模型能力。

### API Key 在这里的价值

- **一个 Key 驱动多个 Agent**：不像聊天工具只能一对一，Agent 框架让你同时派出多个"AI 员工"
- **自动化流水线**：设好流程，它可以每天定时跑，你完全不用管
- **可扩展**：除了 DeepSeek，你还可以接入其他模型的 Key，不同任务用不同模型

### 适合场景

| 场景 | Agent 分工示例 |
|------|---------------|
| 内容生产 | 选题 → 写作 → 校对 → 配图 → 发布 |
| 数据分析 | 采集 → 清洗 → 分析 → 可视化 → 报告 |
| 客服自动化 | 意图识别 → FAQ 匹配 → 人工转接 |
| 代码开发 | 需求分析 → 写代码 → 跑测试 → 修 bug |

### 适合谁？

- 想搭建自己 AI 工作流的进阶用户
- 日常有重复性内容生产需求的人（运营、自媒体、电商）
- 想尝试"多 AI 协作"玩法的探索者

## 第二扇门：Claude Code —— AI 住进你的终端，帮你写代码
![alt text](image/claude.png)

### 它是什么？

Claude Code 是 Anthropic 推出的终端 AI 编程助手。把它装到你的命令行里，一句自然语言描述，它就能读代码、写代码、改 bug、跑测试、甚至管理 Git。

### 跟 CodeBuddy / MarsCode 有什么不同？

 | 工具 | 定位 | 交互方式 |
 |------|------|---------|
 | **CodeBuddy / MarsCode** | 网页/IDE 内的辅助工具，你说需求它出代码 | 你问 → 它答 → 你复制运行 |
 | **Hermes** | Agent 框架，管"模型们怎么协作" | 编排 → 自动执行 |
 | **OpenClaw** | 本地模型管理平台，管"模型跑在哪" | 配置 → 调度 |
 | **Claude Code** | 终端内 AI 程序员，AI 直接操作代码 | 你描述 → AI 直接读写文件、跑命令 |

Claude Code 最大的不同：**它不是"给你建议"，而是直接动手。** 它可以读写你的项目文件、执行终端命令、管理 Git，像一个真正的程序员同事。

### API Key 怎么接入？

Claude Code 使用 Anthropic 的 API Key，配置方式很简单：

```bash
# 在终端设置环境变量
export ANTHROPIC_API_KEY="sk-ant-xxxxxxxxxxxxxxxxxxxxx"

# 然后启动 Claude Code
claude
```

也可以接入其他兼容的 API（如通过 OpenClaw 转发），用你已有的 DeepSeek 或其他模型的 Key。

> 📸 Claude Code 终端界面截图：用中文描述需求，AI 自动写代码

### 它最擅长的三件事

1. **接手陌生项目**：给它一个 GitHub 仓库，它自动分析架构、画出模块关系、帮你快速理解
2. **从需求到上线一条龙**：你说"帮我加一个用户登录功能"，它写代码 + 写测试 + 跑通，你只负责 review
3. **代码审查**：把你的改动丢给它，"帮我 review 这次提交，检查安全问题"

### 适合谁？

- 有编程基础的开发者（需要会用终端和 Git）
- 想大幅提效的程序员
- 想学编程，让 AI 当一对一导师的人

## 第三扇门：OpenClaw —— GitHub 爆火的 Agent 工具
![alt text](image/openclaw3.png)

### 它是什么？

OpenClaw 是一套开源的 LLM 工具链，类比就是**"本地的 AI 运行平台"**。它让你在自己的电脑上管理、切换、运行不同的模型。

### 为什么需要它？

- **隐私**：数据不出你的电脑，适合处理敏感文档
- **离线**：断网也能用，出差、保密环境无压力
- **省钱**：API 按量付费，本地跑免费无限用
- **自由**：想用哪个模型用哪个，不被平台绑定

### API Key 在这里怎么用？

OpenClaw 的核心价值是本地跑模型，但它的另一个重要能力是**作为 API 网关**——你可以把 DeepSeek、通义千问等云端模型的 API Key 配置进去，实现"简单任务本地跑，复杂任务调云端"的智能路由。一个 Key，云端本地无缝切换。

> 💡 **跟前面两个的区别：** Hermes 管"模型怎么协作"，Claude Code 管"AI 帮你写代码"，OpenClaw 管"模型跑在哪"——它是基础设施层，也是 API Key 的本地落点。

### 适合谁？

- 关心数据隐私、不想把敏感文件传到云上的人
- 需要离线使用 AI 的场景（出差、保密环境）
- 想省钱、本地无限调用模型的极客玩家
