1 为什么要本地部署大模型？5 个无法拒绝的理由

📌 1.1 数据隐私——你的秘密，只有你的硬盘知道

这是最重要的理由，没有之一。

云端 AI 的原理是：你的输入 → 传到别人服务器 → 模型处理 → 返回结果。整个过程中，你的数据在别人手里。

本地部署后：所有数据在你自己电脑上流转，不经过任何第三方服务器；断网了也能用，物理隔离；适合处理商业方案、法律文书、医疗记录、个人隐私等敏感信息。

💡 一句话记住：用别人的 AI，等于把你的秘密交给一个陌生人保管。

📌 1.2 离线可用——飞机上、地下室、台风天，AI 不下线

云端 AI 需要联网。但你有没有遇到过：出差高铁上信号断断续续、公司网络限流连 ChatGPT 都打不开、服务器宕机全公司干等着？

本地模型不需要网络。只要电脑有电，AI 就随时在线——对经常出差、网络不稳定、或需要在安全隔离环境工作的人来说，这是刚需。

📌 1.3 零边际成本——用一万次也不多花一分钱

云端 API 按 token 计费。如果你每天和 AI 聊几万字、做大量代码生成——月底账单会让你肉疼。

本地部署：一次性硬件投入（你本来就有电脑）、零使用成本（爱用多少次用多少次）、无 QPS 限制（不会触发"请求过于频繁"）、无内容审查（不用看"作为 AI 助手，我无法……"的脸色）。

📌 1.4 完全可定制——你的 AI，你做主

云端 AI 是"一锅端"的通用模型，没法针对你的需求微调。本地模型可以选编程专用、写作专用、翻译专用模型；喂自己的知识库做 RAG；调整参数控制 AI 的"性格"；甚至用你的数据做微调，打造专属 AI 助手。

📌 1.5 学习 AI 的最好方式

想真正理解大模型怎么工作？最好的方法不是看教程，是亲手部署一个。跑一次本地部署，你会直观理解：模型参数和显存/内存的关系、量化为什么能让 7B 模型装进 8G 显存、token 生成速度如何受硬件制约。

这比读 10 篇科普文章管用。

2 清醒认识——本地部署也有代价

吹完优点，必须把丑话说在前头。本地部署不是万能的。

📌 2.1 硬件门槛——模型越强，要求越高

4-8 GB 内存，无独显 → 1B-3B 小模型，CPU 推理，速度较慢，可以日用

16 GB 内存，无独显 → 1B-7B 模型，7B 用 CPU 跑很慢，3B 以内还行

8 GB 显存（RTX 4060 等） → 7B-8B 量化模型，GPU 推理，流畅 40-60 token/s

16 GB 显存 → 14B 量化模型，接近云端中级模型体验

24 GB 显存 → 32B 量化模型，接近 GPT-4 级别体验

📌 2.2 能力差距——本地模型 ≠ 云端旗舰

实话实说：本地跑的 1B 或 7B 模型，和 ChatGPT-4、Claude 3.5 Sonnet 比，能力上有差距。

1B 模型：能做基本问答、翻译、摘要，复杂推理会翻车

7B 量化模型：日常对话、写作辅助、简单编程够用，复杂任务吃力

14B+ 模型：大部分场景很能打，但需要更好的显卡

💡 关键心态：对 80% 的日常使用场景，7B 模型已经足够好了。

📌 2.3 需要一点动手能力

虽然这篇教程已经尽量傻瓜化，但你还是需要：会用命令行（就是那个黑窗口，别怕）、会下载文件、大概知道自己的电脑配置。如果你完全不会这些——学一下也不亏，这是 AI 时代的必备技能。

📌 2.4 维护成本

模型会更新，Ollama 会升级，可能会遇到兼容性问题。但相比云端服务突然涨价或关停，这点维护成本微不足道。

3 Ollama 是什么？为什么选它？

📌 一句话解释

Ollama 是一个让你在本地电脑上一键运行大模型的工具。

它的设计哲学是：把复杂留给自己，把简单留给用户。不需要懂 Python、不需要配 CUDA 环境、不需要手动下载模型文件——Ollama 帮你把一切都搞定了。

📌 为什么选 Ollama 而不是其他工具？

Ollama ⭐ —— 所有人，尤其是新手，一行命令下载运行，自动管理模型

LM Studio —— 喜欢图形界面，可视化操作，功能不如 Ollama 灵活

llama.cpp —— 进阶用户，性能极致，参数精细控制

vLLM —— 开发者，生产级部署，高并发

对于 95% 的个人用户，Ollama 就是最佳选择。

优点：跨平台（Windows/macOS/Linux 全支持）、模型库丰富（Qwen、Llama、DeepSeek 等主流开源模型，Gemma 等仅作技术对比，国内网络不可用）、自动处理量化（默认下载 Q4_K_M 版本，性价比最优）、提供 REST API（可对接各种前端工具）、活跃社区（问题容易搜到答案）。

4 第一步：在 Windows 上安装 Ollama

📌 4.1 下载安装

① 下载
打开浏览器，访问 Ollama 官网：https://ollama.com，点击首页"Download for Windows"按钮。

② 安装
下载完成后，双击 OllamaSetup.exe 安装，一路点"下一步"即可。

③ 验证
安装完毕后，任务栏右下角会出现一个小羊驼图标 🦙。按 Win + R，输入 cmd 回车，打开命令提示符，输入：

ollama --version

如果显示版本号（如 ollama version is 0.x.x），说明安装成功。

📌 4.2 ⚠️ 重要：修改模型存储路径（别装C盘）

Ollama 默认把模型下载到 C 盘。一个 7B 模型大概 4–5 GB，多下几个 C 盘就爆了。

❌ 不修改的话，模型全塞在 C 盘，空间很快不够用
✅ 改到 D 盘或其他空间充裕的盘

修改步骤：

第 1 步 任务栏右下角 Ollama 图标 → 右键 → Quit Ollama（退出）

第 2 步 按 Win + R，输入 sysdm.cpl 回车 → 打开系统属性

第 3 步 点击 "高级" 标签页 → "环境变量"

第 4 步 在"用户变量"区域，点击 "新建"

第 5 步 变量名填：OLLAMA_MODELS

第 6 步 变量值填路径，比如 D:\OllamaModels

第 7 步 确定保存，重新启动 Ollama（Win 键搜 "Ollama" 点开）

📌 4.3 基础命令速成

以下命令在命令提示符（cmd）或 PowerShell 中运行：

查看已安装的模型：ollama list

下载并运行模型：ollama run qwen2.5:1.5b

只下载不运行：ollama pull qwen2.5:7b

删除模型：ollama rm qwen2.5:1.5b

查看帮助：ollama help

好了，基本功学会，下面进入实战。

5 实战一：1B 小模型——零显卡用户的 AI 入口

🎯 适合人群：没有独立显卡，只有集成显卡，或者电脑配置比较老旧（4–8 GB 内存即可）

模型名称：Qwen2.5:1.5b（通义千问 2.5，15 亿参数）
开发者：阿里巴巴
模型大小：约 0.9 GB
中文能力：★★★★★ 一流
内存需求：最低 4 GB，推荐 8 GB

6 实战二：7B 量化模型——8G 显卡性能全开

🎯 适合人群：拥有 8 GB 及以上显存的 NVIDIA 显卡（RTX 2060 / 3060 / 4060 / 3070 / 2080 等）

📌 6.1 什么是"4bit 量化"？——一文秒懂

一个 7B 参数的模型，如果按原始 FP16 存储，需要 约 14 GB 显存。一张 8 GB 的显卡根本装不下。

但研究发现：把模型参数从 16 位"压缩"到 4 位（精度从 65536 级降到 16 级），输出质量损失极小，体积却能缩到原来的 1/4。这就是 Q4_K_M 量化——性价比之王。

📝 类比：就像一张照片，PNG 原图 20 MB，转成高质量 JPEG 只要 2 MB，肉眼几乎看不出区别。量化就是大模型的"高质量 JPEG 压缩"。

Ollama 默认下载的就是 Q4_K_M 量化版本，你什么都不用操心。

📌 6.2 推荐模型：Qwen2.5:7b

模型名称：Qwen2.5:7b（通义千问 2.5，70 亿参数，Q4_K_M 量化）
开发者：阿里巴巴
模型文件大小：约 4.4 GB
运行时显存占用：约 5.3 GB
剩余显存（8G 卡）：约 2.7 GB，可支持 8K-16K 上下文
中文能力：★★★★★ 顶级开源水平
推理速度：40-60 token/s（RTX 4060）
显卡要求：NVIDIA 8 GB 显存及以上

备选升级：Qwen3:8b（更新更强，约 4.9 GB）；Qwen2.5:14b（14B 参数，约 8.3 GB，需 12-16 GB 显存）。

📌 6.3 部署步骤——同样只需一行命令

ollama run qwen2.5:7b

首次下载 5-15 分钟（模型约 4.4 GB，建议 WiFi 环境）。下载完后进入对话模式，试试它的"真功夫"：

>>> 请你扮演一个资深产品经理，帮我分析一下：我想做一款面向小商家的进销存 SaaS 产品，国内市场还有机会吗？请给出分析框架。

>>> 用 Python 写一个函数，输入一个字符串，判断它是不是有效的 IPv4 地址。要求处理边界情况并加上注释。

>>> 把以下会议记录整理成结构化的会议纪要，包含：会议主题、讨论要点、决议事项和待办事项。

📌 6.4 性能实测（RTX 4060 8GB）

日常聊天（短问答） → 秒回，几乎无等待感
文案写作（800 字） → 约 15-20 秒
Python 代码（50 行） → 约 10-15 秒
中译英（1000 字） → 约 25 秒
文本摘要（3000 字） → 约 30 秒

💡 体感总结：日常使用完全跟手，不会让你想摔键盘。

📌 6.6 小技巧：检查是否在用 GPU

运行模型后，开一个新的命令行窗口，输入：

ollama ps

看到 100% GPU 就说明显卡全力工作中。如果显示 100% CPU，需要检查 NVIDIA 驱动和 CUDA 是否正常。
