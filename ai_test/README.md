## 写作规范

### 与小红书的差异

| 维度 | 小红书 | CSDN |
|------|--------|------|
| 字数 | 600-1000 | 2000-5000 |
| 语气 | 口语化、朋友感 | 专业、严谨 |
| 代码 | 截图或描述 | 直接贴代码块 |
| 结构 | emoji 卡片式 | 章节目录式 |
| 深度 | 点到为止 | 深入原理 |
| emoji | 排版主力 | 辅助点缀 |
| 表格 | 不支持 | 大量使用 |

### CSDN 文章结构模板

```
[开篇：痛点场景/问题引入，200-300字]

## 一、背景与问题分析
## 二、核心概念与原理
## 三、实战代码实现
## 四、AI 协作的切入点
## 五、进阶优化与避坑
## 六、总结与思考

[附录：参考资料/延伸阅读]
```

### 代码规范
- 使用 Python 代码块，标注语言
- 关键行添加注释
- 完整可运行的代码优于片段
- 复杂架构配图（mermaid 或截图）
