## 适配规则

遵循 `douyin_format_guide.md`：

| 改动项 | 小红书 → 抖音 |
|--------|-------------|
| 开头 | 铺垫型 → 第一句直接炸（15-25字） |
| 字数 | 600-1000字 → 300-500字 |
| 段落 | 2-3行/段 → 1-2行/段 |
| emoji | 密集 → 减少30% |
| 互动 | "评论区聊聊一起交流" → "评论区蹲一个比惨的" |
| 收藏引导 | "⭐ 收藏不迷路" → "💾 存着"/"📌 码住不亏" |
| 标签 | `#接口测试 #打工人` → `#接口测试 #程序员日常` |
| 分隔线 | ━━━ 虚线段 → 不用 |
| 图片 | 5-6张 → 4-5张（复用原卡片） |
| BGM | 无 → 必加，轻电子纯音乐，音量30-40% |
