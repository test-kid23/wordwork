## 第一部分：入门教程系列

### 1.1 Claude Code 是什么？——AI 编程助手的正确打开方式
- Claude Code 定位：终端内的 AI 编程搭档
- 和 GitHub Copilot、Cursor 的差异对比
- 核心能力：读代码、写代码、调试、重构、文档生成
- 谁适合用？开发者 / 技术写作 / 自动化脚本
- 上手前需要准备什么（账号、环境、心态）

### 1.2 安装与配置：从零到第一个对话
- 安装方式：npm / 直接下载
- 环境变量配置（ANTHROPIC_API_KEY）
- 与 VS Code / JetBrains 等 IDE 集成
- 第一个实战：让 Claude Code 解读一段已有代码
- 常见安装问题排查

### 1.3 命令行基础 —— CLAUDE.md 与项目上下文
- 什么是 CLAUDE.md，为什么要写
- CLAUDE.md 应该包含什么：项目结构、技术栈、编码规范
- 示例：为一个真实项目编写 CLAUDE.md
- 上下文管理的三个层次：对话内 / CLAUDE.md / 工作区文件
- Hook 机制：自定义工具和脚本集成

### 1.4 Claude Code 的权限模型与安全边界
- 理解权限系统：读/写/执行三种权限
- 如何安全地让 AI 操作你的文件系统
- 白名单与黑名单机制
- 企业场景下的安全建议
