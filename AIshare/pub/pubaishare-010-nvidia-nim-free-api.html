📌 怎么薅到手

① 打开 build.nvidia.com，注册 / 登录 NVIDIA 开发者账号
② 随便点开一个模型页，找「Get API Key」生成你的 key
③ 复制那串 nvapi- 开头的 key，额度直接到账

顺带说一句：你拿到的是通用 key，不是某个模型专属的。在控制台里翻模型列表，看上哪个就把模型名抄走——下面接代码时填进去就行。

📌 想在 Cursor / 自己的脚本里用？

关键就一句：NIM 兼容 OpenAI 协议。你只要把 base_url 指向英伟达的地址，模型名换成控制台里的名字，原来调 OpenAI 的代码原封不动就能跑。

from openai import OpenAI

client = OpenAI(
  api_key="你的nvapi-key",
  base_url="https://integrate.api.nvidia.com/v1"
)

r = client.chat.completions.create(
  model="nvidia/llama-3.1-8b-instruct", # 模型名以控制台为准
  messages=[{"role":"user","content":"帮我写个Python爬虫"}]
)
print(r.choices[0].message.content)

💡 说实话：免费档有速率限制（大概每分钟几十次请求），日常调用、写脚本、给 AI 编程助手当后端完全够；但你要想拿它跑高并发生产，趁早死心，那得加钱买算力。额度用完也不会偷偷扣费，这点比很多「免费试用」良心。

📌 用 CC Switch 接到 Claude Code / Codex

如果你平时用 Claude Code 或 Codex 写代码，上面的代码接入法就有点绕了——每次切模型还得改环境变量。这时候有个免费工具叫 CC Switch（GitHub: farion1231/cc-switch，MIT 协议开源），专门帮你管这事：一个桌面面板，把 NVIDIA NIM 加进去当 provider，然后 Claude Code / Codex 想用哪个模型一键就切。

① 去 GitHub 搜 CC Switch，下载对应系统版本装上
② 在 Providers 里新增一个，填上你的 NVIDIA API key 和 base_url（`https://integrate.api.nvidia.com/v1`）
③ 在 Claude Code / Codex 标签页里选中这个 provider，模型名选好
④ 它自动帮你配好环境变量，打开 Claude Code / Codex 终端就能用

💡 不止 NIM——CC Switch 还支持 OpenRouter、SiliconFlow 等一堆 provider。等于你把所有免费 API 全收进一个面板，按需切，不用再翻文件夹改 .env 了。配合 NVIDIA NIM 免费额度，Claude Code / Codex 的日常编码基本不花钱。
