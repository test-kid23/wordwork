## 0. 先说三个会卡住你的点

你在后台填「AI工具集合」这个名字，保存会报错。而且就算名字过了，菜单也点不动——因为它找不到能跳的地方。所以方案得从这三件事倒推：

| 卡点 | 真实限制 | 解法 |
|---|---|---|
| 名字太长 | 一级菜单 ≤ **4 个汉字**（英文数字按半个汉字折算）。「AI工具集合」= AI(1) + 工具集合(4) = **5 个单位**，超限 | 改「**AI工具箱**」（正好 4 个单位）、或「**AI工具**」 |
| 没地方可跳 | 「跳转网页」只能选**已发布的公众号文章**，或**页面模板** | 先发一篇总目录文章，再回来配菜单 |
| 外链点不了 | 公众号文章正文**不能插外部网址超链接**（跳转小程序除外） | 入口统一写成「App 商店搜 / 微信搜小程序 / 公众号名」，网址只当备注 |

补一条：**个人主体订阅号没有「页面模板」功能**（那是认证号的东西）。所以别去找页面模板，老老实实走「文章 + 合集」这条路，反而更稳。

## 1. 菜单结构

微信的规矩：一级菜单最多 3 个，每个一级下最多 5 个二级，总共只有两级。

### V1 · 最小可行（建议本周就上）

```
[AI工具箱]  [AI实战]  [找我]
   ↓           ↓        ↓
 跳转网页      跳转网页   发送消息
 总目录文章    WorkBuddy 首篇   微信号/合作说明
```

只加一个菜单也完全够用，就是：

```
[AI工具箱] → 跳转网页 → 《AI工具集合》总目录文章
```

为什么建议先做单点深链、不做二级分类：**分类文章还没写，二级菜单点进去是空的，比没有菜单更伤**。等下面第 5 节的分篇文章攒到 4 篇以上，再升级成 V2。

### V2 · 分类展开（分篇文章 ≥ 4 篇时）

```
[AI工具箱]           [AI实战]         [找我]
 ├ 办公提效           ├ WorkBuddy 入门    ├ 我是谁
 ├ 编程开发           ├ CodeBuddy 实战    ├ 加我微信
 ├ 图像视频           ├ 本地部署         └ 商务合作
 ├ 免费羊毛           └ 全部合集
 └ 全部合集
```

注意：一级菜单点了如果挂了二级，就**跳不了网页**（二选一）。所以「AI工具箱」只做展开，「全部合集」放二级里做总入口。

### 菜单和「合集」的关系（这条最值钱）

**已群发的文章正文只能改 20 个字、且只有 1 次机会**。这意味着总目录页发出去以后，你加的链接、删的工具，全都改不了了。

所以真正的"活目录"不是文章，是**合集**：

```
菜单 → 总目录文章（常青，讲分类逻辑，不堆链接）
        └ 文末挂「AI工具集合」合集卡片
             └ 合集里的文章可随时增删，链接永久不变
```

以后每新增一篇工具合集，只往合集里丢，菜单和总目录一个字都不用动。这是绕开改稿限制的唯一稳妥办法。

## 2. 分类体系

### 2.1 为什么不用「对话 / 图像 / 视频」分类

市面上这类文章一抓一大把，都是这么分的。问题是——**读者得先知道工具叫什么，才能按分类找到它**。"我要做视频"这句话翻译成分类，是即梦？可灵？海螺？他不知道，所以还是得搜。

改成按**「你今天要交什么活」**分，读者的起点就变成他自己手里的事：

> ❌ 「AI 图像生成工具合集」
> ✅ 「封面、配图、抠图，一张图就能交的那些工具」

这个分类法还有个好处：同一个工具可以出现在多个模块里（豆包既能在"日常问答"里，也能在"写文案"里），不冲突，反而显得你懂它的边界。

## 3. 排版方案

### 3.1 总目录页的结构（`hub-00-ai-tools-index.html`）

严格遵守 `wx_format_guide.md`，只用 `p/span/strong/br`：

```
分类标签「🧰 AI好物 · 工具总目录」
标题 + 副标题
写在前面（蓝色左边框，痛点直给，不铺垫）
粗分隔线
八个模块导航条（彩色小标签）
粗分隔线
模块 1~8
    ├ 场景标题条（蓝紫交替，写读者的话不写品类名）
    ├ 模块定位一句话
    ├ 3~4 个工具条目（工具名 + 厂商 + 免费标签 + 一句定位 + 入口）
    └ 边界提示 / 个人判断（每个模块换一种写法，不能全都一个模板）
怎么用这份清单（3 条）
我不推荐的做法（否定判断，增强可信度）
结尾（不升华，直接说更新方式）
页脚
```

### 3.2 工具条目卡片规格

```html
<p style="font-size:16px;font-weight:700;color:#1a1a2e;margin:12px 0 4px 0;">
  1. 豆包 · 字节跳动
  <span style="background:#ebf4ff;color:#2b6cb0;font-size:11px;padding:1px 6px;border-radius:4px;">💰 全免费</span>
</p>
<p style="color:#555;font-size:14px;margin:0 0 6px 0;">
  日常问事、写文案、语音闲聊都能接住，国内直连不用折腾。<br>
  <span style="color:#999;font-size:13px;">入口：应用商店搜「豆包」</span>
</p>
```

三条硬规矩：
- **每个工具必须给"怎么找到它"**，不能只给网址（正文外链点不了）
- 免费状态必须是标签，不能藏在句子里（读者扫的是标签）
- 有门槛的（要梯子 / 要显卡 / 要终端）必须打 ⚠️，这是不挨骂的关键

### 3.3 三种标签的固定含义

| 标签 | 色值 | 含义 |
|---|---|---|
| 💰 全免费 | `#ebf4ff` / `#2b6cb0` | 不要钱、不要注册也能用 |
| 🆓 免费额度 | `#f3ebff` / `#6b46c1` | 有免费量，超了要充 |
| ⚠️ 有门槛 | `#fff5f5` / `#9b2c2c` | 要网络条件 / 显卡 / 命令行 |

### 3.4 配图

按 `wx_format_guide.md` 第七章：真实截图优先，密度每 400–600 字一张，每个主要模块至少一张。

总目录页的配图最省力的做法：**拿工具的真实界面截图，横向拼 2–3 张做"这一类的样子"**，红色细框标注每个工具的图标位置。别用 AI 生成的示意图——这类文章读者最认真实界面。

命名：`image/hub-{模块号}-{内容}.png`，例如 `hub-02-workbuddy-desktop.png`。

## 4. 上线操作步骤

1. 先发总目录文章（`hub-00-ai-tools-index.html` → 浏览器打开全选复制 → 粘进公众号编辑器 → 检查排版 → 群发）
2. 发文后，在**文章详情页**复制链接（`mp.weixin.qq.com/s/...`）
3. 后台左侧「自定义菜单」（部分版本在「内容与互动」下）
4. 左侧手机示意图里点「＋ 添加菜单」→ 名称填 **AI工具箱**
5. 右侧「菜单信息」：
   - 消息类型 → 选 **跳转网页**
   - 网页链接 → 点 **从已发布选择** → 找到刚发的那篇
6. 点右下 **保存并发布**
7. 生效时间：几分钟到 24 小时；自己的手机没变就取关再关注一次

**重要**：第 5 步别选「发送消息」——那个只能发文字或已有素材，做不出"目录页"的效果。

## 6. 避坑

- ❌ **别做"100 个 AI 工具大全"**。你的账号定位是"具体场景 + 手把手 + 结果交付"（`PROJECT_CONTEXT.md` 已被数据验证），几十个纯罗列的工具清单点击率很差，而且一周就过期。
- ❌ **别把需要梯子的工具放在前面**。读者点进去打不开，直接取关。全部标注门槛、全部往后放。
- ❌ **别在总目录里塞外链**。正文外链点不了，"阅读原文"只能挂一个，不要浪费在这个页面上。
- ❌ **别一次把 5 个二级菜单铺满**。空菜单比没菜单更伤，先 1 个一级跑两周，看后台的菜单点击次数再决定扩不扩。
- ⚠️ **别用「AI工具集合」这个名字**，保存会报长度超限。
