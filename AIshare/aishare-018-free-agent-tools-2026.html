2 腾讯 WorkBuddy：给不做代码的人用的那个

WorkBuddy 和 CodeBuddy 是腾讯一套体系里的两个门面。CodeBuddy 管写代码，WorkBuddy 管干活——写周报、做 PPT、把一堆 Excel 合并成一张表、爬个网页整理成文档，这类事你不用写一行代码，把需求打进去，它自己拆步骤、自己动手、最后丢给你一个能直接用的文件。

积分这块最舒服的一点是：WorkBuddy 和 CodeBuddy 共用一套账号，积分是互通的。你在 WorkBuddy 上签到的分，转头能在 CodeBuddy 里跑编程任务，反过来也一样。不用两边各攒一份。

① 新用户积分：注册登录后进个人中心手动领，别等它自己到账——这个是要手动领的，有有效期，我第一周就是因为不知道这回事白白亏了。
② 每日签到：每天 100 分，入口在 PC 客户端，手机端和小程序都没有签到按钮，必须在电脑上点。
③ 小程序转盘：这个反过来，只在微信小程序里有，PC 端没有。两头都得跑一趟。

3 阿里 Qoder：这波最实在的是模型免费

四家里我最想让你去试的是 Qoder，理由很直接——它免的不是"次数"，是模型本身。

Qwen3.8-Flash 从 9 月 18 日上午十点开始限时免费，在这期间你用它跑任务一点 Credits 都不扣。注意这个差别：很多工具送的额度是"给你 2000 分，用完为止"，而 Qoder 这个是用这个模型就不花钱，你套餐里的额度和每天领的那 100 分可以原封不动留给别的模型。等于白送你一个能跑满月的主力模型。

用法也没什么门槛，桌面端打开，在模型选择器里切到 Qwen3.8-Flash 就行，不用单独报名，不用填什么申请码。

4 字节 Trae：送得最多，也最需要算着用

Trae 以前的口号是"个人版永久免费"，暑假里悄悄换了个玩法：把"速通次数"改成了积分制。从那之后，免费还在，但感觉不一样了。

新注册给 4000 积分这个事是真的（通用 2000 + Work 专属 2000，官方活动页上写的是新用户领 4500）。加上每日签到、邀请好友、老用户升级，累计最高能凑到 14000 分。免费版每个月还额外有 500 通用积分兜底。

❌ 有个坑得提前说：Trae 的积分用完不会直接停，但会给你降权——任务排队排得特别长，响应慢得像回到拨号上网的年代。
✅ 所以用之前先养成习惯：看一眼剩余积分，把大任务放在积分充裕的时候跑。

5 如果你是学生或者老师，先别急着按上面那样算

这块单独拎出来说，因为额度差得不是一点半点。

🎓 QoderWork 高校师生认证：学信网或者教育邮箱认证通过后，学生拿 4000 积分，老师拿 6000 积分，认证完自动到账。
🎓 阿里 AI 公益支持计划：9 月下旬起，千问办公和 Qoder 面向部分高校的在册师生提供为期一年的免费授权，教学、科研、课程实践都能用。
🎓 GitHub Copilot 学生认证：有 .edu 邮箱的话可以直接升 Pro，额度放开、模型能手动切。
🎓 千问办公：网页端注册就送 2000 积分，不用下载 App，浏览器打开直接用。

不是学生也没关系，这几家的个人免费版该有的功能都有，只是额度紧一些，日常用够了。

6 光看福利不够，我让它们现场打了一架

送多少积分只是价格战，工具好不好使还得看东西做出来什么样。所以我干了一件更较真的事：用同一个需求，让这几家各写一个贪吃蛇游戏，全程录屏，中间不帮它补需求、不改代码。

需求就一句话，谁也没多给提示：

"用 HTML + CSS + JavaScript 写一个贪吃蛇游戏，单个 HTML 文件，方向键控制，吃食物加分，撞墙和撞自己结束，有分数显示和重新开始按钮。"

结果比我想的平淡：这几家基本都在 1 到 3 分钟内把活交了，生成的游戏全都能正常运行。没有一个翻车的，也没有谁快到能拉开差距。所以对比表格我不做了——横竖都是"能跑"，硬凑一张表反而像在编数据。

7 还有一个得花钱的：Claude Code + CC Switch + DeepSeek

前面几家都是免费的，但我也得诚实点说：免费额度用完的时候，写复杂东西的手感确实不一样。我现在的日常是上面这些轮着免费用，遇到真正难啃的活儿，切到我付费的那套上去。

这套搭配长这样：Claude Code 当客户端，CC Switch 当切换器，后端接我自己充了钱的 DeepSeek。

Claude Code 是 Anthropic 官方的命令行编程工具，纯终端，没有界面，但它的工作流设计在同类里是第一梯队的——自己找文件、自己改、自己跑测试、自己收尾。问题在于它默认连的是 Claude 官方模型，价格不便宜，国内直连也麻烦。

CC Switch 就是来解决这个的。它是个开源的小工具（GitHub 上搜 farion1231/cc-switch），作用很朴素：把 Claude Code 的供应商配置可视化管理起来，点一下就切换。不用你去翻配置文件、手改环境变量。我本机装的就是它，常驻在托盘里。

里面要填的东西就这么几个，填错一个就连不上：

供应商：DeepSeek（CC Switch 里有现成预设，选上就行）
请求地址：https://api.deepseek.com/anthropic —— 必须走 Anthropic 兼容接口，这一步填错就报连不上
主力模型：deepseek-v4-pro[1m]
子任务模型：deepseek-v4-flash —— 内部轻量调用走这个，省额度

🔧 操作顺序：去 DeepSeek 开放平台充点钱、建个 API Key → 打开 CC Switch，添加供应商，选 DeepSeek 预设，把 Key 填进去 → 核对一遍上面那几项 → 点启用 → 把旧终端窗口全关掉重开，不然还是老配置 → 敲 claude 验证。

为什么愿意为它花钱？因为 DeepSeek 的 API 单价摆在那，充一次能用很久，而换来的是 Claude Code 那套成熟工作流加上一个不怵复杂逻辑的模型。我个人的排序是：日常小活儿用免费的，架构和重构这种一动就伤筋动骨的活，切付费这套。混着用，一个月花不了几十块。

⚠️ 但别一股脑全注册一遍

✅ 值得动手的：
• 平时要处理表格、周报、PPT 的——WorkBuddy 和千问办公这俩拿了先用
• 写代码的——Qoder 这个月的 Qwen3.8-Flash 免费额度别浪费，白送一个月主力模型
• 手里有 GitHub 账号、只想补全的——Copilot 免费版装了就完事
• 在校学生、老师——先去认证，4000 积分和一年免费授权自己会到账

❌ 但下面这几种情况，先别急着装：
• 想靠签到攒积分当主力用——签到给的那点分，认真干两三个任务就没了，别把工作流押在签到上
• 已经在用某个工具用得很顺——别为了几百分的羊毛搬家，迁移成本比积分值钱
• 一次把五家全注册了——五个客户端、五套账号、五个活动页，你不会有精力都点一遍，挑两个真需要的
• 想拿它替代人做判断——工具再强，返工成本还是你自己扛

写在最后

这波补贴战对咱们普通用户是好事，能白嫖的时候别客气。但也别把心思全花在"哪个又送了多少分"上面——工具换来换去，活儿还是那些活儿。你把一句话需求说清楚，比攒多少积分都管用。
