## 副文章格式规范

与主文章（长文教程类）不同，AIshare 系列采用**轻副文章格式**：

```
分类标签 → 标题 → 一句话引入（蓝框）→ 粗分隔线
→ 工具列表（分类小标题 + 逐个工具卡片）
→ 速查总结 → 结尾号召 → 页脚
```

**工具卡片模板：**
```
## 序号. 工具名 · 入口
> 一句话描述核心功能
> 💡 一句话：为什么值得收藏
```

**关键规则：**
- 每篇控制在 5-8 个推荐，不堆数量
- 每个工具必须给真实入口（网址/小程序搜索名）
- 禁止空泛评价，必须说清楚「能解决什么问题」
- 严格遵循 `wx_format_guide.md` 标签和配色规范
