📌 想拿免费 API KEY 在别处用？

WorkBuddy 那两周免费是产品端促销，只在它家 App 里用。但 Hy3 在腾讯云 TokenHub 上另有新用户福利：直接领 100 万 tokens 免费额度，90 天有效。最关键的一点——Hy3 兼容 OpenAI 协议。也就是说你拿到的是标准 API KEY，把代码里的地址和 key 一换，Cursor、你自己的脚本、任何 OpenAI SDK 都能直接调，逻辑一行都不用改。

from openai import OpenAI

client = OpenAI(
  api_key="你的TokenHub_API_KEY",
  base_url="TokenHub控制台给的地址" # Hy3兼容OpenAI协议
)

r = client.chat.completions.create(
  model="hunyuan-hy3", # 模型名以控制台显示为准
  messages=[{"role":"user","content":"帮我写个Python爬虫"}]
)
print(r.choices[0].message.content)

💡 说实话：免费额度用完后自动停，不会偷偷扣费。想接着用，Hy3 的 API 才 1 元/百万 tokens 输入，便宜到没感觉。想彻底零成本，还能走另一条路——Hy3 是 Apache 2.0 开源，权重在 GitHub / HuggingFace / ModelScope 都能下，自己用 vLLM 起个本地服务，自己给自己发 API，永久免调用费（当然得你有显卡）。
