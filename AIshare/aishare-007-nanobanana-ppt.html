📌 它到底是什么？

🔗 github.com/op7418/NanoBanana-PPT-Skills
📦 作者歸藏，一个把 Google Nano Banana Pro 图像模型和可灵 AI 视频模型串起来的 PPT 生成工具。你给一段文字/文档/大纲，它自动规划幻灯片结构，生成精美 16:9 图片，还能加转场动画，最后导出一个能播放的完整视频。
💡 一句话：做 PPT 这件事，终于从 "半天的手工活" 变成了 "一分钟的指挥活"。

📌 5个核心能力，个个打到痛点

1 智能文档分析——你给内容，它定结构

📦 不是简单把你的文字贴到PPT里——它会提取核心要点、规划页码、决定每页放什么。你扔一篇长文档进去，它自己判断应该拆成 8 页还是 15 页，每页什么主题，逻辑怎么串。
💡 我试过的：扔了一篇 3000 字的技术分享稿进去，它自动规划了 12 页。说实话，这个结构比我手动做的还合理——至少它不会犯"一页塞太多字"的错。

2 双风格设计——不花哨但有品味

📦 内置两种风格：「渐变毛玻璃卡片」和「矢量插画」。不搞那些花里胡哨的模板，走简洁专业路线。支持 2K/4K 分辨率，16:9 比例。因为样式是通过提示词定义的，你完全可以照着它的格式自己写新的风格。
💡 一句话：比大多数人在网上随便下载的模板好看得多，关键是风格统一——不会出现第三页和第五页像两个不同人做的。

3 AI视频转场——每页之间不是硬切

📦 这可能是最让我惊喜的功能。它用可灵 AI 在两个页面之间生成流畅的过渡动画——不是 PPT 自带的那种生硬翻页，而是真正的视觉过渡。还支持首页循环预览，开场先播一小段动画吸引注意力。
💡 注意：视频功能需要可灵 AI 的 API Key，有成本。如果只是做静态 PPT，只用 Google Gemini API 就够了（有免费额度）。

4 交互式播放器——直接在浏览器里讲PPT

📦 生成的不只是图片——还带一个HTML 交互式播放器。视频和图片混合播放，键盘左右键翻页，跟正经 PPT 软件一样。不用装任何东西，发一个 HTML 文件给对方就能看。
💡 实际场景：远程分享方案演示时，你发链接过去，对方在自己浏览器里翻页看——比传PPT文件体面多了。

5 完整 MP4 导出——发视频比发文件香

📦 用 FFmpeg 把所有页面和转场动画合成一个完整 MP4 视频，统一 1080p、24fps。你可以在不打开任何PPT软件的情况下，发一个视频给客户/老板/观众看完整演示。
💡 坦白说：这个功能的设置门槛不低——要装 FFmpeg、配可灵 API。如果你不是技术背景，建议先只用静态图片输出，够用了。

⚠️ 不是所有人都适合——听完再决定装不装

✅ 适合你，如果你：
• 讨厌做 PPT，但有定期做演示的需求
• 有 Google Gemini API Key（免费额度就够）
• 内容本身已经想好了，只是不想花时间排版
• 想做视频形式的方案演示，不是传统PPT

❌ 先别装，如果你：
• 期望"什么都不用管，AI 连内容带设计全搞定"——这个工具需要你先有内容
• 对画面有极度的自定义需求——它走的是模板化自动生成路线，不是Figma级别的精细控制
• 没用过命令行——目前需要跑 Python 脚本，纯图形界面还没有

📌 怎么开始？

第一步：git clone https://github.com/op7418/NanoBanana-PPT-Skills.git
第二步：pip install google-genai pillow python-dotenv
第三步：去 Google AI Studio 拿免费 API Key，配置 .env 文件
第四步：python generate_ppt.py "你的内容" --style gradient-glass
搞定。完整文档看仓库的 QUICKSTART.md。

📌 也支持作为 Claude Code Skill 安装（/ppt-generator-pro），用自然语言一句话生成。

🎯 对我来说最大的价值不是"省时间"——是做出来的东西比自己手动调的看起来更专业。自己做的 PPT 总有一种"业余味"：字体不统一、间距不舒服、配色奇怪。这个工具至少保证了底线。剩下的精力，你可以花在打磨内容上——那才是 PPT 真正重要的部分。
