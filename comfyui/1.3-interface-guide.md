# 节点界面完全解读

> 打开 ComfyUI 看到一堆框和线？这篇把每个按钮、每条线、每个面板给你拆清楚。看完你就知道那些"老手嗖嗖连节点"在干什么。

---

## 先别怕：这界面就是张流程图

许多人第一次打开 ComfyUI，看到花花绿绿的方框和线，反应跟我当初一样："这什么鬼？"

冷静三秒钟。你看看这张图的逻辑到底是什么：

- **方框 = 操作步骤**（加载模型、写 prompt、采样、保存）
- **线 = 数据流动方向**（模型的输出传给采样器，采样器的输出传给解码器）
- **画布 = 你的操作空间**（把步骤拖开、连线、调整）

换句话说——你在 PowerPoint 里画过一次业务流程图吧？ComfyUI 的画布就是那玩意，只不过连上线之后它真的会执行。

## 画布基本操作：10 个动作就够了

### 1. 双击空白 → 搜索面板

这是你用得最多的操作。双击画布任意空白位置，弹出一个搜索框。输入"KSampler"→ 回车，一个采样器节点就出现在画布上了。不用去菜单里找、不用记位置——**搜就完事了。**

搜索面板是 ComfyUI 最重要的交互入口。你不需要记住所有节点名字，记关键词就行——"Load""VAE""Save""Clip""Lora""ControlNet"。输入前几个字母就出来了。

### 2. 拖拽连线

鼠标移到节点的输出点（右边的小圆点）→ 按住拖到另一个节点的输入点（左边的小圆点）→ 松手，线就连上了。

颜色的含义：
- **蓝色** = 模型数据（model）
- **粉色/紫色** = 潜空间数据（latent）
- **橙色** = VAE 数据
- **黄色** = CLIP 数据（文本编码）
- **绿色** = 条件数据（conditioning，正向/负向 prompt）
- **灰色** = 图片数据（image）

颜色不是装饰——它告诉你这条线在传递什么类型的数据。**同色可以相连，不同色连不上去。** 你要把 KSampler 的输出连到 Save Image？行，但你可能中间需要 VAE Decode 把潜空间转成图片格式。

> 一个常见错误：把 Latent 直接连给 Save Image。你会得到一个报错——因为 Save Image 要的是 image 类型，不是 latent。中间必须过 VAE Decode。

### 3. 断开连线

在已连的线上点一下选中它，按 Delete，线就断了。

或者把鼠标悬停在线和节点的连接处，按住 Ctrl 拖走——线就脱了。这招熟练了之后快点。

### 4. 节点参数调节

点击节点本身，右侧面板出现它的参数列表。常见参数类型：

- **数字框**（步数、CFG、种子）：可以直接输入，也可以用鼠标按住数字拖动微调
- **下拉菜单**（采样器类型、调度器、模型选择）：展开选择
- **文本框**（prompt、负向 prompt）：输入文本
- **开关（Toggle）**：开/关

还有一个隐藏操作：**右键点击数字参数 → 选"Convert to Widget" → 转成可连线输入**。比如你的采样步数不想写死，而是想用另一个节点动态控制——把它转成输入口，从外部连线进来。

### 5. 画布缩放和平移

- **滚轮** = 缩放
- **按住 Ctrl + 滚轮** = 精细缩放（调得更慢更精确）
- **按住空格 + 拖拽** = 平移画布
- **鼠标中键拖拽** = 也是平移

如果你的工作流很大（几十个节点），双击空白处输入空格 → 按下空格键再拖鼠标，画布就跟着你走了。

### 6. 框选

按住鼠标左键拖拽一个矩形区域 → 区域内所有节点被选中。然后你可以：
- 拖走整组
- Ctrl+C 复制整组
- Delete 删除整组

对于"复制一套节点去试另一组参数"这种操作特别方便。

### 7-10. 这几个动作凑一起说

- **选中节点 → Delete**：删除
- **选中节点 → 按住 Ctrl 拖拽**：复制节点（连已有连线一起复制）
- **右键画布空白**：上下文菜单（添加节点、整理布局、设置等）
- **Ctrl+Shift+V**：粘贴节点并保留原始连线结构

## 核心快捷键速记

不用全背，前 8 个记住就行。

| 快捷键 | 功能 | 使用频率 |
|--------|------|---------|
| `Ctrl+Enter` | 将当前工作流加入生成队列 | 每分钟按一次 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 | 经常 |
| `Ctrl+S` / `Ctrl+O` | 保存 / 加载工作流 | 经常 |
| `Ctrl+C` / `Ctrl+V` | 复制 / 粘贴节点 | 经常 |
| `Ctrl+Shift+V` | 粘贴并保留连线结构 | 偶尔 |
| `Ctrl+D` | 加载默认工作流 | 常用 |
| `Q` | 打开/关闭任务队列面板 | 常用 |
| `H` | 打开/关闭历史记录面板 | 常用 |
| `Delete` | 删除选中节点 | 常用 |
| `双击空白` | 搜索并添加节点 | 最常用 |
| `Ctrl+A` | 全选画布节点 | 偶尔 |
| `Ctrl+B` | 将选中节点折叠为子图（bypass）| 偶尔 |

说实话，我用了半年之后，日常用的就这几个：
- 双击搜索加节点
- Ctrl+Enter 跑图
- Ctrl+S 保存工作流
- Ctrl+C/V 复制粘贴

其他快捷键不是你"不熟"，是真的用不上那么频繁。别给自己"背快捷键"的压力，用了自然记住。

## 右侧面板三大区域

ComfyUI 界面右侧有三个可切换的面板标签。

### 节点属性面板

选中任意节点后，这个面板显示它的所有参数。你可以在这里改 prompt、调步数、换模型——跟直接在节点上调是一样的。我个人习惯直接在节点上改参数（不用移鼠标过去面板），但参数多了面板看着更清楚。

### 任务队列面板（按 `Q` 打开）

这个面板是 ComfyUI 比 A1111 聪明很多的地方。

ComfyUI 用的是**异步队列系统**。啥意思？你点"生成"之后，整张图开始按节点顺序执行。如果你跑了 20 步，结果不满意，在节点里把步数改成 30→ 重新点生成 → **ComfyUI 只重新执行变更了的节点和它下游的节点。** 上游没变的部分直接复用之前的缓存结果。

举个例子：你的工作流是"加载模型 → 写 prompt → 采样 20 步 → 解码 → 保存"。跑完之后，你把 prompt 改了一个词，再点生成。A1111 会从头跑；ComfyUI 只重新跑"写 prompt → 采样 → 解码 → 保存"，模型加载那步直接跳过。

**这个设计在你跑大型工作流时能省大量时间。** 比如视频生成，模型加载可能要几十秒，如果每次微调 prompt 都重新加载模型，你会疯的。

队列面板还可以：
- 查看当前正在生成的任务进度
- 取消排队中的任务
- 查看任务耗时分布（哪个节点花了多少秒）

### 历史记录面板（按 `H` 打开）

每次生成的图片都在这里存着。点一下可以回看原图、查看对应的 prompt 和参数，还可以右键 → "Load" 把那次生成的工作流重新加载到画布上。

这个功能解决了"三天前的图怎么调出来"的问题——在历史记录里找到那张图，Load 工作流，所有参数原样回来。这也是 PNG 内嵌工作流的体现：你生成过的每张图都带了"食谱"。

## 理解节点类型分类

ComfyUI 的节点虽然多，但按功能分就五类。记住这个分类，你不会迷路。

| 类型 | 功能 | 典型节点 |
|------|------|---------|
| **加载器 (Loader)** | 把模型、图片、素材加载进来 | Load Checkpoint、Load VAE、Load Image、Load LoRA |
| **编码器 (Encoder)** | 把人类看得懂的输入转成 AI 能算的格式 | CLIP Text Encode、VAE Encode |
| **采样器 (Sampler)** | 核心计算——在潜空间里迭代生成 | KSampler、KSampler Advanced |
| **解码器 (Decoder)** | 把 AI 算出来的格式转回人能看的图片 | VAE Decode |
| **保存器 (Saver)** | 把结果存到硬盘 | Save Image、Save Animation |

这五个类型串成一个环：**加载 → 编码 → 采样 → 解码 → 保存。**

不管多复杂的工作流——ControlNet、LoRA、IPAdapter、Upscale、视频生成——底层都是在这个环上增加分支。"我看不懂一张复杂工作流"的感觉，本质上是"我还没看懂它的主干环在哪儿"。先找主干，再逐分支理解。

## 写在最后

这界面看着吓人，实际核心操作就三件事：**双击搜节点 → 拖线连上 → Ctrl+Enter 跑图。**

你不需要第一天就记住所有面板、所有颜色、所有快捷键。下一次你打开 ComfyUI 的时候，试着用键盘搜一个节点加进去、手动连上线、跑一张图。做一次你就知道——原来所谓"复杂界面"只是把"选模型+调参数+点生成"这三步展开了而已。

下篇我们来做第一件正事：从零搭一个真正管用的文生图工作流。不是默认模板那种"能跑就行"的水平，而是你以后能拿来改、拿来复用的工作底盘。
