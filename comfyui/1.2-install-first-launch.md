# 安装与首次启动：从零到出第一张图

> 三种安装方式、GPU 支持矩阵、模型去哪下载、放哪个文件夹。每一步都说清楚，装完就能出图。

---

## 选哪个安装方式？直说

ComfyUI 有三种安装方式。别纠结，我对号入座给你说清楚。

### Windows/macOS 桌面应用（最推荐新手）

ComfyUI 官方出了桌面版，一键安装，自带运行环境，不用配 Python、不用pip install 半天。Windows 和 macOS 都支持。

**适合你，如果你：**
- 第一次装 ComfyUI
- 不想折腾环境配置
- 就想双击打开、点生成、看结果

到 [ComfyUI 官网](https://www.comfy.org/) 下载对应的桌面安装包，装完打开就是 ComfyUI 界面直接能用。这是我现在给朋友推荐的方式，也是最省心的方式。有人会说"手动装更灵活"——等你真需要灵活的时候再考虑手动装，新手期别给自己找麻烦。

### Windows 便携包（解压即用）

官方也提供 Windows 便携包，不需要安装，解压到任意文件夹就能跑。针对不同 GPU 有三个版本：

| 版本 | 适用显卡 |
|------|---------|
| **NVIDIA GPU** | 几乎所有 NVIDIA 显卡（GTX 10 系及以上） |
| **AMD GPU** | AMD 显卡（Windows 下实验性，不太稳） |
| **Intel Arc** | Intel 独立显卡（A 系列等） |

每个版本内置了对应平台的 PyTorch 环境。便携包的好处是干净——不动系统环境，删掉文件夹等于完全卸载。

**适合你，如果你：**
- 不想往系统里装东西
- 可能需要同时跑多个版本的 ComfyUI（确实有人这样）
- 公司电脑有权限限制装不了程序

### 手动安装（pip，给 Linux 和进阶用户）

```
git clone https://github.com/comfyanonymous/ComfyUI
cd ComfyUI
pip install -r requirements.txt
python main.py
```

三行命令搞定。但前提是你的 Python 环境、CUDA Toolkit、PyTorch 版本都配好了——而"配好"这三个字，对新手来说是最大的坑。如果你用的是 Linux 服务器，这个方法最适合。个人电脑的话，桌面版不用折腾。

## 你的 GPU 能不能跑？

先说好消息：ComfyUI 支持的 GPU 平台可能是所有开源项目里最全的。

| 平台 | 状态 | 备注 |
|------|------|------|
| **NVIDIA (CUDA)** | 最佳 | 所有主流生图模型都最先支持 CUDA |
| **AMD Linux (ROCm)** | 良好 | AMD 卡在 Linux 下体验接近 NVIDIA |
| **AMD Windows** | 实验性 | 能跑但偶尔有坑，效率不如 Linux |
| **Intel Arc (XPU)** | 支持 | Intel 独显可用，但社区资源较少 |
| **Apple Silicon (M1/M2/M3)** | 良好 | M 系列芯片体验不错，尤其 M3 Max |
| **华为昇腾 NPU** | 支持 | 国产硬件方案 |
| **MLU (寒武纪)** | 支持 | 同上 |
| **Iluvatar** | 支持 | 同上 |

**没 GPU 怎么办？**

- `python main.py --cpu`：纯 CPU 模式——能跑，但慢。一张 512×512 可能要几分钟。
- **Comfy Cloud**：官方的云端方案，浏览器里直接用，按用量付费。如果你只是想试试 ComfyUI 是什么感觉、不打算长期本地跑，云方案够用了。

如果你处于"还不知道要不要深入"的阶段，先别买卡。用 Comfy Cloud 玩两天，确定自己真需要本地跑再考虑硬件。

## 模型去哪下载？

ComfyUI 是空的——装好之后没有模型。你得自己下。两个主要地方：

### Civitai（civitai.com）
全球最大的 AI 生图模型分享社区。SDXL、Flux、Pony 系列的模型和 LoRA 这里都有。按下载量和评分排序，一般不踩坑。

**我的下载原则**：先看用户发的示例图，至少看 10 张——不是看"好不好看"，是看"稳定性"。同一个 prompt 出了 10 张图，人脸是不是都正常、手指有没有崩、背景有没有奇怪的变形。一个模型如果 10 张里有 3 张以上有明显问题，即使剩下 7 张很惊艳我也不用。稳定性比单张质量重要。

### Hugging Face（huggingface.co）
更偏"开发侧"，官方的 Flux、SD 3.5、Hunyuan Video 这些基础模型都在 Hugging Face 首发。下载时需要能访问外网——如果你网络条件有限，国内有镜像源和网盘分流，社区搜一下能找到。

**新手推荐清单（按优先级排）：**

| 优先级 | 模型 | 用途 | 大小 |
|--------|------|------|------|
| 必下 | Z-Image-Turbo FP8 | 主力生图，8G/16G 都能跑 | ~6GB |
| 推荐 | SDXL 基础模型 | 生态最全的底盘 | ~7GB |
| 推荐 | SD 3.5 Medium | 比 SDXL 快、比 Flux 轻 | ~5GB |
| 按需 | Flux.1 Dev FP8 | 最高画质但要 16G | ~14GB |
| 按需 | Hunyuan Video 1.5 | 视频生成 | ~12GB |

不用全下。先下 Z-Image-Turbo 和 一个 SDXL 打底，跑起来再说。具体的模型推荐和显存需求我在上一篇（0.1）里写得很细，没看过的可以先去看看。

## 模型放哪个文件夹？

ComfyUI 的模型目录结构是固定的，别乱放。

```
ComfyUI/
├── models/
│   ├── checkpoints/      ← 主模型文件（.safetensors / .ckpt）
│   ├── vae/              ← VAE（.safetensors）
│   ├── loras/            ← LoRA（.safetensors）
│   ├── controlnet/       ← ControlNet 模型
│   ├── clip/             ← CLIP 模型（部分新模型需要单独放）
│   ├── unet/             ← UNET（Flux 等模型用）
│   ├── upscale_models/   ← 放大模型（用于图像超分）
│   └── diffusion_models/ ← 扩散模型
```

简单规则：
- 大模型文件 → `checkpoints/`
- LoRA → `loras/`
- VAE → `vae/`
- ControlNet → `controlnet/`

模型文件名一般是 `.safetensors`。如果你下了 `.ckpt` 格式的，功能一样，放同一个文件夹就行。

## 启动 & 出第一张图

### 1. 启动 ComfyUI

桌面版：双击图标打开。

手动装：在 ComfyUI 目录下运行：

```
python main.py
```

终端会输出类似：

```
Total VRAM 16376 MB, total RAM 32684 MB
pytorch version: 2.5.1+cu124

Starting server

To see the GUI go to: http://127.0.0.1:8188
```

打开浏览器访问 `http://127.0.0.1:8188`，你就能看到那个经典的节点画布了。

### 2. 加载默认工作流

第一次打开，画布上可能一片空白。点右上角或按快捷键 `Ctrl+D`，ComfyUI 会加载默认的 txt2img 工作流——就是上篇讲的那六个节点：

```
Load Checkpoint → CLIP Text Encode (+/-) → Empty Latent Image → KSampler → VAE Decode → Save Image
```

### 3. 选模型

找到 `Load Checkpoint` 节点，下拉菜单里选你放进 `checkpoints/` 文件夹的模型。如果没有出现你刚放的模型，点旁边的刷新按钮。搜一下也很快——现在 ComfyUI 支持在 Load Checkpoint 节点里直接搜模型名。

### 4. 写 Prompt

`CLIP Text Encode (Positive Prompt)` 节点里写你想要的画面，`CLIP Text Encode (Negative Prompt)` 节点里写你不想要的。写中文也行、英文也行，取决于你用的模型支持哪种语言。

**第一个 prompt 建议：**

先别写"一个赛博朋克风格的少女站在霓虹灯下的雨巷里穿着汉服打着油纸伞"，那种 prompt 试一次等半天出来不对，挫败感很强。先写简单的验证环境没问题：

```
a cute cat sitting on a desk, natural lighting
```

负向 prompt：

```
bad quality, blurry, deformed
```

### 5. 设分辨率

`Empty Latent Image` 节点里设 `width` 和 `height`。新手建议 512×512 或 768×512，别一上来就 1024×1024——生成慢、容易爆显存，万一崩了你不知道是模型问题还是显存问题。

### 6. 点生成

点右上角的 Queue Prompt 按钮，或者按 `Ctrl+Enter`。

如果你的显卡风扇开始转、终端开始打印 `100%|████████████████████|`——恭喜你，它在跑了。

大概 5 到 20 秒（看你的显卡和模型大小），图片出现在 Save Image 节点下面。右键 → Open Image 可以放大看原图。

**你出了第一张图。** 这就是 ComfyUI 的起点。

## 容易踩的坑

**"Load Checkpoint 下拉是空的"**

模型没放对位置。确认文件在 `models/checkpoints/` 下，格式是 `.safetensors` 或 `.ckpt`。放了之后点 Load Checkpoint 节点上的刷新按钮。

**"OOM"（Out of Memory，显存爆了）**

把 Empty Latent Image 的分辨率调低——比如从 1024 改成 512。如果还是 OOM，在启动命令里加 `--lowvram`：`python main.py --lowvram`（手动安装）；桌面版在设置里找 Low VRAM 模式。但这终归是权宜之计——模型选型我在 0.1 篇里写了，8G 卡该用什么模型有明确推荐。

**"生成的图是黑的/花的"**

大概率 VAE 没配好。有些模型需要手动选 VAE，Load Checkpoint 节点右上角有 VAE 选择器。也有可能是你下的模型文件损坏了，重新下载试试。

**"`python main.py` 报错 ModuleNotFoundError"**

缺少依赖。确保你在 ComfyUI 目录下跑了 `pip install -r requirements.txt`。如果是桌面版应该没有这个问题——桌面版自带所有依赖。
