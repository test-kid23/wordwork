🪄 核心魔法：extract 变量传递
第1步 · 创建
extract: user_id
POST 创建用户后，从响应体把 user_id 抠出来存好
→
第2步 · 查询
GET /users/{{user_id}}
直接用花括号引用刚存的 id，查到这个用户
第3步 · 更新
PUT /users/{{user_id}}
同样是 {{user_id}}，改邮箱密码都没问题
→
第4步 · 删除
DELETE /users/{{user_id}}
删完不留脏数据，数据库干干净净
全程没有一行变量赋值代码 · 自动串起来 🔗
