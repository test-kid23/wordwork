- **内容**: 左右双栏对比 Python 30行 vs YAML 10行
- **布局**: comparison
- **预设**: sketch-notes + comparison

### 03-content-flow（三步工作流 · flow）
- **内容**: 定义请求 → 定义断言 → 跑
- **布局**: flow（左到右三步箭头）
- **预设**: hand-drawn-edu

### 04-content-dense（5大优势 · dense）
- **内容**: 5个核心优势要点卡
- **布局**: dense
- **预设**: sketch-card

### 05-ending（结尾CTA · sparse）
- **内容**: 互动引导 + 下篇预告 + 话题标签
- **布局**: sparse
- **预设**: sketch-summary
