✅ YAML写测试比Python好在哪？真实对比来了


写了八年测试 框架换了好几轮

说点大实话


1️⃣ 学习成本

Python：要会import、class、def、fixture
YAML：知道接口协议就能写

不是谁都会Python 但谁都能看懂接口文档


2️⃣ 可读性

Python代码 逻辑藏在if/for/try里
YAML一眼看清接口地址、参数、期望结果

产品经理："哦 这个我懂"
开发："你给我看Python代码我不看 YAML可以"


3️⃣ 维护成本

接口加了字段 → Python要改N个地方 → 容易漏
YAML改一行配置 → 整个套件生效


4️⃣ 局限性

非常复杂的业务逻辑还是得写代码
但80%的接口测试场景 YAML足够了


💡 一句话

不是谁比谁好 是用对场景

简单重复的接口测试 → YAML省心
复杂业务流程编排 → Python兜底
