# 🚦 聪明的测试知道什么时候不跑


你有没有遇到过 生产环境不敢跑全量测试

创建用户？删数据？这谁敢在线上跑啊

但有些测试（查询、健康检查）又确实要在生产跑


## 🤔 传统做法很蠢

手动注释掉不想跑的case → 跑完再取消注释 → 某次忘取消 → 生产出Bug


## ✅ 条件跳过

```yaml
  - name: 删除测试用户
    skip:
      if: "{{env}} == 'production'"
      reason: "生产环境不能删数据"
    request:
      method: DELETE
      url: /api/v1/users/{{user_id}}
```

生产自动跳过 不用手动改任何东西


## 三个经典场景

1. 生产环境跳过写操作
2. 第三方服务挂了 跳过依赖它的case
3. 版本升级 跳过不兼容的旧测试

```yaml
skip: { if: "{{version}} < 2.0", reason: "旧版本不支持" }
```

核心一句话：**不跑比跑错更高级**
