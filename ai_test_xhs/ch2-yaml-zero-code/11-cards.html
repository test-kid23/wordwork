⚡ 两种写法 · 一套CRUD

❌ Python

conftest.py / test_create.py / test_query.py / test_update.py / test_delete.py

5个文件 · ~150行

变量靠全局传 · import一堆 · 易改漏

✅ YAML

就一个 users.yaml

1个文件 · ~60行

extract自动串联user_id · 零import · 改一个地方就行

💡 YAML 三大核心优势
📝
声明式
描述"测什么"，不用写"怎么测"
🔗
零 import
不用导入 pytest / requests / 任何库
🔄
自动串联
extract 变量在 case 间自动流转
🎯
一文件到底
增删改查全在一个 YAML 里搞定
⚠️ 不是行数的差距
是搞错一个变量就能让你找半小时

🪄 核心魔法：extract 变量传递
1️⃣
extract: user_id · POST 创建用户后，从响应体把 user_id 抠出来存好
2️⃣
GET /users/{{user_id}} · 直接用花括号引用刚存的 id，查到这个用户
3️⃣
PUT /users/{{user_id}} · 改邮箱密码都没问题
4️⃣
DELETE /users/{{user_id}} · 删完不留脏数据，库干干净净
🎯 零代码背后的哲学
你不是在"写测试脚本"
你是在声明：
对哪个接口 · 做什么操作 · 期望什么结果
框架帮你跑，变量帮你传
全程没有一行变量赋值代码 · 自动串起来 🔗
