📌 五步走

1️⃣ 装依赖
命令行装一下需要的包
一行命令的事

2️⃣ 建文件
在 local 文件夹下
新建一个 hello.yaml

3️⃣ 写套件名和地址
给套件起个名
写上要测的 base_url

4️⃣ 写第一个请求
来个最简单的 GET
比如查个首页接口

5️⃣ 加断言
验状态码是 200
验返回里有个关键字段


🚀 跑起来

命令行指到 local 文件夹
指定 dev 环境 跑
加个 -v 看详细

五分钟 第一个测试通过🎉
那种爽感你试试就知道
