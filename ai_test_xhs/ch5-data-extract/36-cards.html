⚙️ SQL怎么配
🎯
SELECT精准字段
别 SELECT *。精准捞需要的列：SELECT id,status,createtime FROM users WHERE id=之前存的变量值
🔑
列名就是变量名
查到 status 字段 → 存入 {{status}} → 断言 status=1 表示创建成功
🔐
别用生产环境测
读操作可以连生产从库。写操作一定指定测试库，别污染线上数据。
示例：注册后验库
创建接口返回uid → 存为{{uid}} → SQL用uid查
SELECT id,status FROM users WHERE id={{uid}}
