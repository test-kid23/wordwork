# AI Web 自动化测试课程大纲

> 来源：VIP-AI 全栈测试专家课程思维导图
> 整理时间：2025-06-26

---

## 课程概览

**核心理念**：Playwright 基础 + AI 协作编程的学习方式

**四层 Web 自动化能力模型**：
- 第一层：Playwright 编程脚本 ⭐3+
- 第二层：元素定位与视觉模型混合框架 ⭐3+
- 第三层：DOM Agent 快速探索 ⭐3+
- 第四层：视觉 Agent 页面理解 ⭐3+

---

## 模块一：Web 自动化策略与页面认知 ⭐3

### 1.1 Web 自动化目标与边界 ⭐4+
- 什么该自动化、什么不该自动化
- ROI 评估：投入产出比分析
- 自动化测试金字塔

### 1.2 浏览器、DOM 与视觉页面 ⭐5+
- 浏览器渲染原理
- DOM 树结构解析
- 视觉页面 vs DOM 结构的差异
- Shadow DOM、iframe 处理

### 1.3 自动化路径选择 ⭐5+
- 传统脚本驱动 vs AI 视觉驱动
- 不同技术路线的适用场景
- 混合策略的选择逻辑

---

## 模块二：Playwright 核心编程与 AI 协作实现 ⭐5

### 2.1 先掌握最小浏览器自动化链路 ⭐10+
- 环境安装与配置
- 启动浏览器、打开页面、关闭浏览器
- 点击、输入、等待的基本操作
- 断言页面状态
- 学员亲自完成一条完整链路：打开 → 操作 → 断言 → 关闭

### 2.2 AI 辅助生成并审核稳定 Locator ⭐7+
- 什么是稳定的元素定位
- Playwright 定位策略：role、text、CSS、XPath
- AI 辅助生成 Locator：描述页面元素让 AI 推荐定位方式
- 审核 AI 生成的 Locator：是否稳定、是否可维护
- 处理动态 ID、复杂层级结构的定位技巧

### 2.3 从"能操作"补强为"能验证" ⭐6+
- 操作成功 ≠ 业务成功
- 页面状态验证 vs 业务结果验证
- 等待策略：显式等待、隐式等待、智能等待
- 处理异步加载、动画过渡
- AI 辅助判断页面视觉正确性

## 模块九：三类路径的转化与协作 ⭐3+

**三种自动化路径的对比与选择**：

| 路径 | 代表工具 | 优势 | 适用场景 |
|------|----------|------|----------|
| 脚本驱动 | Playwright | 稳定、可控、CI 友好 | 核心流程回归测试 |
| DOM Agent | Playwright CLI Agent | 快速探索、无需维护脚本 | 探索性测试、临时验证 |
| 视觉 Agent | Midscene.js | 无需理解 DOM、自然语言驱动 | 页面结构频繁变化、复杂视觉验证 |

- 三类路径的互补使用策略
- 根据项目阶段选择主力方案
- 混合框架的设计思路
