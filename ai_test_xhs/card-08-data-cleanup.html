🧪 一个完整的测试 = 四个阶段
🛠 准备数据 + 🧪 执行测试 + ✅ 验证结果 + 🧹 清理数据
🛠
准备阶段 setup
🔹 创建测试用户
🔹 创建测试订单
🧪
执行阶段 main
🔹 查询订单
🔹 验证返回字段
🧹
清理阶段 teardown
🔹 删除测试订单
🔹 删除测试用户
✅ 跑完后数据库像没跑过一样干净
这才是专业
✅ Setup & Teardown 黄金法则
1️⃣
setup 只做"测试能跑的最小准备" — 需要什么就准备什么，不要顺手多创建不相关的数据
2️⃣
teardown 做到"比测试前还干净" — 删除所有创建的数据，恢复被修改的状态
3️⃣
套件级清理兜底 — 每个用例清理自己 + 套件结束时全量清理（双重保险）
4️⃣
失败也要清理！ — 不要把清理放在"只有通过才执行"的逻辑里，失败时的残留更危险
