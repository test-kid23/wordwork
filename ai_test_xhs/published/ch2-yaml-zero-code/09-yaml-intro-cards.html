📊 命令式 vs 声明式 — 一张图看懂差距
❌ Python 命令式
30+行代码
改一个字段
→ 改 N 个文件
换测试环境
→ 改代码
团队协作
→ 只有开发看得懂
✅ YAML 声明式
~10行配置
改一个字段
→ 改 1 行
换测试环境
→ 换 1 个参数
团队协作
→ 产品经理都能看懂
💡 就像点菜：命令式是"去冰箱拿鸡蛋打散热油……"
声明式是"来一份番茄炒蛋"
