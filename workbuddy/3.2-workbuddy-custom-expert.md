# 每次都要重打一遍需求？我造了个专属专家，以后一句话开工

## 先说这次的起因

先说我干过的一件蠢事。

我朋友开了家四十平的小面馆，每月的活动方案是我帮他做。第一次我交代得很细：

"预算 2000 以内，客群是周边上班族和带孩子的家长，不能亏本，赠品成本你算进去，话术别太油，别写'限时疯抢'。"

第二次、第三次……我还是得重新打一遍——因为 AI 不记得我上次说过什么，我也懒得翻聊天记录去复制。

直到第 N 次打完，我才反应过来：**每天浪费我最多时间的地方，不是它干得慢，是我在重复交代同一件事。**

这篇讲的就是怎么一次性解决它：**给自己造一个专属专家。**

## 1. 先拆清楚：专家 / 技能 / 连接器，分别管什么

动手之前得先分清三个词，不然很容易白折腾。

我总结成一个人体的比喻：

- **专家（Expert）= 大脑**——管"谁来做"。有角色、有方法论、有自己的一套规矩；
- **技能（Skill）= 双手**——管"按什么方法做"。一段可以反复调用的方法或工具包；
- **连接器（Connector）= 管道**——管"数据从哪来"。把 WorkBuddy 跟外部服务接起来。

对应到实际使用，就是三个问题：**谁来做（专家）、用什么方法做（技能）、连到哪里做（连接器）。**

前面有一篇讲的是官方专家中心里现成的专家——那是**别人造好的大脑**。这篇要讲的，是**你自己造一个**。

（技能和连接器，下一篇单独讲。）

## 2. 什么样的活，值得做成专家

不是所有活都值得。我第一反应是想造个"万能助手"，后来发现那是错的。

值得做成专家的活，通常满足三条：

1. **高频**——你每周甚至每天都在干；
2. **有固定的流程或格式**——每次都要交代同样的背景和要求；
3. **带你的个人偏好**——你的文风、你们公司的模板格式、你的判断标准。

我给自己列的清单是这样的：

| 活 | 判断 | 原因 |
|---|---|---|
| 门店活动方案（预算 + 客群 + 不许亏本） | ✅ 值得 | 每月都做，规则完全一样 |
| 月度经营小结（给合伙人看） | ✅ 值得 | 每月一次，格式固定，数据来自同一张表 |
| 供应商比价 + 问价话术 | ✅ 值得 | 高频，判断标准固定（含运费、含税、起订量） |
| 帮朋友想一句开业标语 | ❌ 不值得 | 一次性，做完就完了 |
| 每次临时冒出来的想法 | ❌ 不值得 | 每次都不一样，没有固定套路 |

一句话判断：**如果同样一句话你说过三遍以上，它就值得固化。**

## 3. 怎么造：入口在哪、要准备什么

入口是 **专家中心 → 我的专家 → 创建专家（"+"）**。

点进去之后，它不是甩给你一堆表格让你填，而是**让 AI 带着你做**——它会先加载一个官方的专家管理技能，然后一步一步问你：

- 这个专家是谁、负责哪一类活？
- 它擅长什么、按什么方法干？
- 交出来的东西长什么样？

**你真正要准备的，只有一件事：把自己的经验说清楚。**

我把这个过程拆成五块，你也可以照着这五块想：

| 要交代的 | 你要回答的问题 |
|---|---|
| **角色定义** | 它是谁？替谁干哪一类活？ |
| **核心能力** | 3–5 条，具体到能执行（别写"擅长运营"这种空话） |
| **工作流程** | 接到需求先干什么、再干什么？ |
| **输出规范** | 交出来的东西要什么格式、什么风格？ |
| **注意事项** | 哪些事不许干（不许编数据、不许用某些词） |

核心就一句话：**把你脑子里那些"我以为它知道"的规矩，写下来。**

## 4. 我造的两个专家，长这样

一个管"门店活动"，一个管"外贸开发信"。一个是帮朋友看店，一个是我自己的活。**配置文案我全给你，能直接抄。**

### ① 门店活动专家（可直接抄的配置）

**角色定义**：你是一家社区小店的兼职运营，帮店主做每月活动方案与配套物料文案。店主不懂营销，你要说人话。

**核心能力**：
- 在"预算 ≤ X 元、不得亏本"的硬约束下出方案；
- 把活动拆成"怎么让人来 / 来了买什么 / 怎么让他再来"三步；
- 输出方案、海报文案骨架、店员话术三份东西。

**工作流程**：先问清客单价、毛利、可让利额度、活动周期 → 给 3 个方案（成本从低到高）→ 我选一个 → 再展开成物料清单与话术。

**输出规范**：方案用表格；海报只给文案骨架，不给成品图；话术每条不超过 3 句、能直接照着念；金额写区间并标"按实际成本核"。

**注意事项**：不许编造"日均客流""复购率"这类数据；不许用"限时疯抢""爆款"这类词；赠品成本必须计入，不许假装免费。

造完第一次用它，我说的是："用活动专家，给面馆做个五月活动，客单 28，毛利 60%，最多让利 2000。"

**它先反问我三个问题**（活动周期、有没有人手、能不能提前备货），然后给了三套方案，成本分别 380 / 900 / 1850。

这个"先反问"就是人设起作用的信号——**普通对话里，它经常直接就编了。**

### ② 外贸开发信专家

**角色定义**：你是外贸业务员的写信助手，只写第一封开发信和后续跟进信。

**核心能力**：按客户类型分三套切入（价格型 / 交期型 / 定制型）；每封不超过 120 词；开头不许用 Dear Sir。

**工作流程**：先确认产品、目标市场、客户类型 → 出 3 个版本 → 我选 → 再生成第 2、3 封跟进。

**输出规范**：英文正文；每封给一行中文说明"这封打的是哪个点"。

**注意事项**：**认证、材质、产能、交期只能引用我给的信息**，缺就留【待确认】；不许写"我们是行业领先"这类空话。

这两个专家有个共同点：**它们不是"帮我写东西"，而是"按我的规矩把活干完"。**

## 5. 造完怎么用：一句话开工

这部分最爽的地方在于：**以前要交代五句话，现在只要一句。**

**以前**：帮我想个活动，预算 2000，客群是周边上班族，不能亏本，赠品成本算进去，话术别太油……
**现在**：用活动专家，给面馆做个五月活动。

它自己会去翻它的规矩。

更好用的是**三段式指令**：

> **文件夹路径 + 素材清单 + 具体任务**

比如："素材在 `D:/面馆/五月活动/`，里面有上月流水、现行菜单、赠品报价单，用活动专家出一版方案。"

缺什么它会主动问，不会自己编。

## 6. 三个坑，先替你踩了

**① 一上来就想造个"什么都能干"的专家**

**表现**：定位写成"帮我处理各种工作"，用起来跟直接对话没区别。

**真相**：专家越宽，"人设"越虚。它不知道自己在替哪个岗位干活，就退化成普通对话。

**解法**：一个专家只管一类活。宁可造三个窄的，别造一个宽的。

**② 经验写得太虚，等于没写**

**表现**：核心能力写"擅长内容创作"，工作流程写"根据需求生成内容"。

**真相**：这些话它本来就会说。你真正值钱的经验是具体的——比如"金额必须标'按实际成本核'""话术每条不超过 3 句"。

**解法**：每写一条，问自己"这是不是一条能照着做的动作"。

**③ 造完就不管了**

**表现**：用几次发现它老犯同一个错，就放弃了。

**真相**：第一版专家一定不完美。它的价值恰恰在于**可迭代**——补一条规矩进去，下次就不犯了。

**解法**：头两周每次用完记一句"这次哪儿不对"，攒几条一起改。

## 写在最后

造专家这件事的本质，不是"多了一个工具"，而是**把你脑子里那些说不清的隐性经验，变成能反复执行的显性规矩。**

通用专家给你的，是平均答案；专属专家给你的，是**你的答案**。

花半小时造一个，往后每次调用都在复用这份投入——这是我目前觉得性价比最高的一个功能。

下一篇讲"技能"：专家是大脑，技能是它的手。同样是官方和社区都有的东西，怎么挑、怎么装、装上之后差别在哪。
