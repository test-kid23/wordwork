## 先说这篇是什么

这个系列写了十几篇，评论区被要得最多的一样东西是：

**"你把那些句式整理给我吧。"**

这篇就是那份整理。我把前面用过的所有句式，按场景汇总成一份清单——**不讲解、不铺垫，你直接抄。**

先说清楚一件事：**这些模板不是"话术"，不是靠花言巧语骗 AI 听话。** 它们的作用只有一个——**把你脑子里那些默认的要求，变成它能看见的要求。**

你不说"给谁看"，它就只能按平均来；你不说"不许编数字"，它就真会编。

> 🖼️ **【配图1】** 本文结构示意：一个通用骨架 + 分场景模板 + 三条保命句

## 1. 先记住一个通用骨架

如果这篇你只记一条，记这个：

> **要什么 + 给谁用 + 什么感觉**

举例：

- ❌ "帮我写一篇介绍产品的文章"
- ✅ "写一篇产品介绍，给第一次听说我们的中小企业老板看，语气实在、别用营销腔，800 字以内"

区别不在礼貌，在**它有没有判断标准**。

**这条骨架适用于 80% 的需求**——写东西、做页面、出图、做方案，都能套。

## 2. 分场景模板（照抄就行）

> 每条模板后面我都加了一行 **🔁 换行业**——同一个骨架，换三个词就是另一个行业的活。

### ① 做网站

骨架：**给谁看 + 放什么 + 什么感觉**

> "做一个预约页，给附近 3 公里的上班族订位；首屏要有 3 个招牌菜 + 一个'立即订位'按钮；风格干净、主色深绿；表单只要称呼、人数、到店时间、电话。"

多页站再加一层**页面地图**：

> "要做 4 个页面：首页 / 产品列表 / 单个产品详情 / 联系我。导航在每页顶部，点击可以互相跳转；风格要统一。"

> 🔁 换行业：外贸 → "英文独立站：首页 / 产品分类 / 单品页 / 询盘页，客户是德国中小批发商"；自由职业 → "作品集：商业 / 人像 / 活动三类 + 报价页"。

### ② 出图 / 做设计

骨架：**用在哪 + 画什么 + 什么感觉 + 文字放哪**

> "做一张 A5 双面菜单卡；正面 3 款产品，每款留图片位、名称、价格、一句卖点；风格奶油白 + 焦糖色，干净、留白多；**只出背景和版式，不要生成任何文字**，文字我自己叠。"

记住一个附加要求：**要放字的图，明确说"只出背景，不要生成文字"**——AI 画的字，十个里错八个。

> 🔁 换行业：电商 → "产品主图 3 张方向，第一张突出'不用打孔'，只出背景"；设计/摄影 → "报价单 PDF 三档版式，冷静、少形容词"。

### ③ 做调研

快查骨架：**对象 + 范围 + 格式 + 要求**

> "帮我查一下本地 3 公里内私房烘焙的同款价格带；只看近一年的公开信息；输出成一页要点；每一条都标来源。"

系统调研再加三条硬要求：

> "写一份决策调研报告。要求：① 先给结论，再给依据；② 所有数据必须标注来源，没有可靠来源的一律留【待核实】占位，不许自己编；③ 最后给我 3 条明确建议，别只说'视情况而定'。"

> 🔁 再加一句最值钱的："**同时告诉我，这件事哪些不能做**"——资质、红线、平台规则，它不说你就得自己撞。

### ④ 写文档（周报 / 方案 / PRD / SOP）

写之前先答三个问题：**给谁看 + 要达成什么 + 希望他看完做什么**。

两段式（推荐）：

> 第一轮："我要写一份 XX 方案，先只给我大纲，每个章节配一句话说明，不要展开。"
> 第二轮："按这个大纲写第一章，其他章节先不动。"

去 AI 味的三个要求：

> "① 不要用'随着……的发展'这类开头；② 语气像跟同事当面说；③ 所有数字如果不确定，留【待补】占位，不许编。"

> 🔁 换行业：老师 → "三套分层练习 + 答案 + 易错点"；工厂 → "作业指导书：工序、工具、公差、常见错误、安全检查项"；工程 → "给甲方的周报：进度、问题、谁在什么时候解决"。

### ⑤ 做小程序

**关键前提：需求里必须明确写"微信小程序"**，否则它会给你生成网页。

> "帮我做一个'活动报名'微信小程序；用户是公司同事；要保存报名数据；流程是：打开→填表→提交→看到自己的报名结果。"

> 🔁 换行业：门店 → "预订小程序：选产品、选取货时间、填忌口、提交"；外贸 → "样品申请小程序：选型号、填公司、留联系方式"。

### ⑥ 同时开多个任务（并行）

拆任务的三条标准：**能独立验收 + 输入输出不重叠 + 各有明确交付物**。

每条需求后面都加一句输出目录：

> "……所有文件输出到 content/ 目录。"
> "……所有文件输出到 design/ 目录。"

这句话能避免一个很常见的翻车：两条线生成同名文件，后写的把先写的覆盖掉。

> 🔁 换行业：投标 → "技术标 / 商务标 / 资质扫描"三个目录分开；老师 → "练习 / 课件 / 家长会材料"分开。

### ⑦ 造专属专家

五块内容：**角色定义 + 核心能力（3–5 条）+ 工作流程 + 输出规范 + 注意事项**。

其中"注意事项"最值钱，写的是禁区：

> "不许编数据；不许用'限时疯抢、爆款'这类词；赠品成本必须计入，不许假装免费。"

用的时候一行搞定：

> "用活动专家，给这家面馆出个五月活动。"

> 🔁 换行业：外贸 → "开发信专家"；老师 → "出卷专家（含难度配比、答案、易错点）"；HR → "制度修订专家（含改动对照）"。

### ⑧ 报价单 / 条款清单（最容易被忽略，但最值钱）

骨架：**分几档 + 含什么 + 不含什么 + 有效期**

> "做一份报价单：分三档（基础 / 标准 / 加急），每档写清包含什么、**不包含什么**、改稿或返工怎么算、报价有效期几天；金额写区间，标'以最终确认为准'。"

> 🔁 换行业：设计 → 按半天/全天；外贸 → 阶梯价、起订量、贸易术语；工程 → 分项工程量清单。

### ⑨ 问价话术库（比写文案有用得多）

骨架：**场景分类 + 每条不超过 3 句 + 能直接发**

> "写 20 条问价话术，分四类：问价格、问配送/交期、问能不能定制、催单；每条不超过 3 句，微信里能直接发；不许用'亲''宝子'，不许承诺我没说过的事。"

> 🔁 换行业：老师 → "家长十问回复"；客服 → "退款/差评/物流三类回复"；HR → "候选人十问"。

## 3. 三条"保命句"，加在任何需求后面

这三句话，我建议你做成固定结尾，每次加上：

1. **"没有可靠来源的数据，一律留【待核实】占位，不许自己编。"**
   —— 这是最重要的一句。AI 最危险的错不是答错，是答得像对的。
2. **"信息不够就直接问我，别自己假设。"**
   —— 防止它替你脑补关键前提。
3. **"所有文件输出到 xxx/ 目录。"**
   —— 防止文件被覆盖、也方便你回头找。

## 4. 一份反面清单：这些话等于没说

同样重要的，是知道什么话别讲：

- ❌ **"帮我做个好看的"** —— "好看"不是标准，它只能给平均答案；
- ❌ **"写得专业一点"** —— 给谁看的专业？专业到什么程度？
- ❌ **"多加点数据"** —— 数据从哪来？没说清就等于让它编；
- ❌ **"你自己看着办"** —— 它不会知道你的偏好，只会给你最常见的那种；
- ❌ **"先随便做一版，不行再改"** —— 改一轮的成本，往往比说清楚一次高。

**说白了：凡是不能用"给谁、做什么、什么样"回答的要求，都是无效要求。**

## 写在最后

这份清单不是让你每次都抄一遍，而是**当个起点**。

最好的做法是：**你抄一次，然后按自己的情况改一改，存到备忘录里。** 改过两三次，它就是你自己的模板了。

如果你连"改"都嫌麻烦，还有更省事的办法：**把这五块写进一个专属专家里（我讲专属专家那篇讲过），以后一句话就够了。**

到这里，4.x 的选型、避坑、成本、模板都讲完了。这个系列上半程（1.x 到 4.x）也就完整了——从"它是什么"，到"怎么用"，再到"怎么用得省心、不翻车"。

如果这个系列帮你少走了几步弯路，那就值了。
