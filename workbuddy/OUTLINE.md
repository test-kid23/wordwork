## 系列定位

WorkBuddy 是腾讯推出的 **AI Agent 办公工具 / 全场景 AI 工作台**：不说代码、不装环境，用大白话说出需求，它自主规划并交付多模态复杂任务结果，支持多个 AI Agent 并行干活。

这个系列和 `codebuddy/`（AI 编程搭档，面向会写一点代码的人）形成互补：

| | **WorkBuddy** | **CodeBuddy** |
|---|---|---|
| **一句话定位** | 场景化 AI 全家桶，说需求拿成品 | AI 编程搭档，深度嵌入开发工作流 |
| **目标用户** | 完全不会写代码的普通人、设计师、运营、创业者 | 开发者、技术写作者、想学编程的人 |
| **核心场景** | 设计、做网站、做调研、写文档、数据分析 | 写代码、改代码、跑自动化任务 |
| **使用方式** | 网页/桌面打开，说人话，拿成品 | IDE / 插件 / CLI，逐文件协作 |
| **特色能力** | AI 专家团、多 Agent 并行、本地文件直读、远程控制 | Skills 机制、MCP 协议、Automations 定时任务 |

> 一句话卖点：**不会写代码的人，也能让 AI 干大活。**
