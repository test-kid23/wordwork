# 单页网站"能用"了，但我让 WorkBuddy 把它升级成了真站

> 系列：WorkBuddy 实战教程 · 第 7 篇
> 关键词：WorkBuddy 建站进阶、多页面网站、博客站、静态托管上线、内容站

---

## 先说升级的起因

上一篇我用 WorkBuddy 做了个单页个人主页，30 分钟搞定，当时觉得"够了"。

一个月后问题来了：文章从 5 篇变成 20 篇，单页上那个"我的文章"越拉越长。朋友问我"你写过一篇讲选课工具的文章是哪篇？"我翻了半天。一个页面当名片用没问题，当内容站用就开始别扭了。

于是我想让它升级成"真站"：首页 + 文章列表 + 文章详情 + 关于我，页面之间能点来点去。这篇记录的就是这次升级的全过程。

## 1. 升级前，先画一张"页面地图"

单页是"一条路走到黑"，多页是"几个房间串起来"。动手前得先想清楚：**这个站要几个页面？页面之间怎么跳？**

我拿纸画了一张很丑的图，逻辑就四类：

1. **首页**：一句话介绍 + 最新 3 篇文章 + 两个入口按钮（看全部文章 / 关于我）
2. **文章列表页**：全部文章，标题 + 日期 + 分类，按时间排
3. **文章详情页**：点开某一篇看到正文，同一个模板套所有文章
4. **关于我**：自我介绍 + 联系方式

画完我发现，**全部内容就装在这四类页面里**，谁也跑不出去。这张图就是后面所有需求的地基。

## 2. 把地图说成一段需求

打开 WorkBuddy，新建任务，工作空间还是原来那个文件夹（升级要在原站基础上做）。把地图翻译成大白话发给它：

> "把工作空间里那个单页个人主页，升级成一个多页面网站：一共四个页面——首页、文章列表页、文章详情页、关于我。每个页面顶部有导航栏，可以互相跳转。首页放我的介绍和最新 3 篇文章入口；文章列表页按时间列出所有文章；点标题进文章详情页；关于我放介绍和联系方式。保持原来的深色蓝主题和风格，四个页面视觉统一，手机上打开也要正常。"

跟上一篇对比，这次需求多了一样东西：**"几个页面 + 页面之间怎么跳"**。多页站点最核心的就是把"结构"交代清楚，它才能把页面串成站。

> 🖼️ **【配图2】** 升级需求指令输入框截图（红框标注：四个页面 / 导航跳转 / 风格统一）

## 3. 看它把"整站"搭起来

发出去之后，你能明显感觉到这次和单页不一样：它会先搭整站骨架，再一页一页填。

拆解过程大致是：梳理四个页面的结构 → 建一套共用导航和样式 → 分别生成首页、列表页、详情页模板、关于我 → 把页面用链接串起来 → 汇总交付。

任务完成后，打开工作空间，你会看到**一组文件而不是一个文件**——首页、列表页、详情页、关于我，各是各的。点开任一个，导航都在，页面能互相跳转。

第一次跑多页站点会慢一点，几分钟打底，正常。

## 4. 往里填你自己的真内容

AI 生成的是"壳"，内容是模板。接下来把真东西放进去，我是这么干的：

- 把公众号最近的 10 篇文章标题和正文，分批**贴进对话**，让它填进列表页和详情页；
- 关于我页面，把真实的介绍和联系方式告诉它，让它替换；
- 让它在每篇文章下加"上一篇 / 下一篇"跳转，逛起来更顺。

填完内容，**逐字校对一遍**是必须的——标题错一个字、正文串了行，AI 不会脸红，但你得负责。

如果你不习惯在对话里贴大段文字，还有个笨办法：生成的文件用文本编辑器打开，把文字替换成自己的（跟你改 Word 一样，保存后刷新浏览器就生效），不碰代码也能改内容。

> 🖼️ **【配图5】** 文章内容贴入对话 + 填好真实文章后的列表页 / 详情页预览

## 5. 像逛网站一样验收

多页站验收不能只看一个页面，要**从头到尾逛一遍**：

1. 首页的三个入口，点进去都对吗？
2. 列表页每篇文章，点开能到对应的详情页吗？
3. 详情页能回到列表、回到首页吗？
4. 手机宽度下，导航和正文乱不乱？

逛出来毛病，照旧追加一句话，它接着改。我那次改了导航在手机上的间距、详情页的字号两处，几分钟搞定。

## 6. 从"自己能用"到"别人能用"

升级完的站，本地浏览器随时能看。但如果想让别人也访问，分三档：

**第一档 · 自己看 / 局域网传着看**：文件在你电脑上，你自己打开就能用，适合"先跑起来"。

**第二档 · 上线给所有人**：把你工作空间里的这个网站文件夹，拖到支持静态网站的托管平台（一般都有免费额度），它会给你一个 https 开头的网址。把网址发出去，任何人点开就能访问。这就是上一篇说的"上线"，到这一步，**不用买域名也已经有公网链接了**；想更正式，再买个域名绑上去。

**第三档 · 加互动功能（进阶，量力而行）**：如果你以后想要"用户注册、留言存储、数据统计"这类功能，那就需要后端和数据库了——纯静态托管撑不住。WorkBuddy 给你的是网页文件（前端），接数据库是另一门课，通常要配云开发或 Serverless 服务。**对个人内容站来说，第二档够用很久，别急着上第三档。**

## 写在最后

回头看这次升级，单页解决"有没有"，多页解决"装不装得下"。

WorkBuddy 帮你干掉的永远是"搭骨架、写代码"这部分，而**"站里要装什么、怎么串起来"必须你自己想清楚**——好在想清楚只需要画一张很丑的图。

下一篇回到调研：1.4 我们讲过随手查，这篇讲**大决定前的系统调研**——拿不准要不要做一件事时，怎么让 WorkBuddy 给你出一份能拍板的调研报告。

到时候见。
