# 下载了 WorkBuddy 却不知道说什么？15 分钟跑通第一个任务

> 系列：WorkBuddy 入门教程 · 第 2 篇
> 关键词：WorkBuddy 新手教程、第一次使用、创建任务、需求描述、零代码

---

## 先说个扎心的现象

上一篇发出去之后，好几个人私信我：你说得天花乱坠，我下载了 WorkBuddy，打开之后对着屏幕发呆——**不知道第一句话该说什么。**

这个反应我太熟了。

因为我第一次用的时候也这样。以前用 ChatGPT，打开就知道要干嘛：问问题呗。但 WorkBuddy 是个"干活"的工具，你反而不会说话了——它不像聊天框，更像你把一个任务交给了一个刚入职的新同事，你得把话说清楚，它才知道从哪下手。

这篇就是来解决这个问题的。**不聊概念，纯操作**，跟着我的步骤走，15 分钟，你会拿下第一个成品。

## 第一步：从哪打开它

WorkBuddy 有两个入口，你选一个就行：

| 入口 | 怎么进 | 适合谁 |
|------|--------|--------|
| **桌面客户端** | 官网下载 Windows / macOS 版 | 主力使用，能操作本地文件 |
| **网页版** | 浏览器打开官网直接登录 | 临时用、不想装软件 |

我的建议：**想认真用，就装桌面版。** 原因很简单——WorkBuddy 最大的本事之一是"读取你授权过的本地文件夹，帮你处理文件"。这个能力只有桌面版发挥得最完整。装完记得勾选"创建桌面快捷方式"。

## 第二步：登录之后，先把"工作空间"定下来

下载装好后，点开客户端，登录很简单：**微信扫码，或者手机号验证码**，几秒钟的事，没有那么多套路。

但登录完别急着发需求——先做一件新手最容易跳过的事：**把"工作空间"定下来。**

工作空间是什么？一句话：**告诉 AI 去哪个文件夹干活。**

在"新建任务"的输入框左下角，能看到一个"选择工作空间"的入口——刚用的人很容易忽略它。点开，选一个专门放 AI 成果的文件夹，建议在桌面或文档下新建一个，比如就叫 `MyAI`，以后固定用它。

为什么值得花这十秒钟：

1. **资料放这儿，它才找得到**：想让 AI 读你手上的资料（文档、表格、截图），把文件放进这个文件夹，它干起活来才顺；
2. **产物集中，好管理**：生成的东西都围绕这个文件夹，不会散落得满电脑都是；
3. **固定一个，长期省心**：官方也建议固定一个文件夹。每次新建任务，顺手确认工作空间还是它，以后找文件不迷路。

一个 `MyAI` 文件夹，每次新建任务顺手确认一下，**两秒钟的动作，省掉以后满电脑找文件的麻烦。**

> 🖼️ **【配图2】** 新建任务界面："选择工作空间"入口（红框标注，建议固定在同一个文件夹）

## 第三步：认识界面，记住三个位置就够

登录进去，别被一堆按钮吓到。你只需要记住**三个位置**：

```
┌─────────┬──────────────┬─────────────┐
│ 左侧     │    中间       │   右侧      │
│ 导航栏   │   工作区      │  对话面板   │
│ 新建任务 │ 执行过程+     │ 输入框+     │
│ 专家中心 │ 结果预览      │   回复      │
└─────────┴──────────────┴─────────────┘
```

- **左侧**：导航栏。**新建任务**、专家中心、技能市场都在这，入口就这几个，用多了自然熟。
- **中间**：工作区。任务执行的进度、生成的结果、文件操作都在这边展示。
- **右侧**：对话面板。你的需求输入框在这，和 AI 的对话也在这。

顶部还有一条工具栏：可以**切换 AI 模型**（混元、DeepSeek 等几个可选，旁边标着积分消耗倍率），还能直接看到**积分余额**。新手阶段，模型用默认的就够——快、省积分，别在这上面纠结。

> 🖼️ **【配图3】** 登录后的工作台主界面全景：左导航栏 + 中工作区 + 右对话面板（红框标注顶部模型切换与积分余额）

## 第四步：第一句话到底怎么说

这是所有人都卡住的地方。我总结了一个**"三要素"需求模板**，照着填就行：

```
[你要什么] + [给谁用/用在哪] + [什么风格或要求]
```

拿我自己举例。我第一次认真下的任务是做个人介绍页，我当时是这么说的：

> "帮我做一个个人介绍页面，深色背景，左边是我的简介和头像，右边放我的文章标题列表，整体要看起来专业，手机上看也不乱。"

拆开看：
- **要什么**：一个个人介绍页面
- **给谁用/用在哪**：手机上看也不乱（暗示要响应式）
- **风格要求**：深色背景、专业

再给你一个反面例子，我朋友一开始是这么说的：

> "做个页面。" ❌

完了。没有风格、没有内容、没有用途。AI 只能瞎猜，猜出来当然不是你要的。**需求越具体，结果越接近你要的。** 这不是什么 prompt 技巧，就是平时你交代同事干活的样子。

> 🖼️ **【配图4】** 输入框特写：一条完整的三要素需求指令（红框标注"要什么+给谁用+风格"三段）

## 第五步：跑通你的第一个任务

现在正式开干。我带你完整走一遍我那次做个人介绍页的过程：

**① 输入需求**，点发送。

**② 观察它开始"干活"**：你不会等来一句回答，而是看到它自己开始拆解任务——理解需求 → 规划步骤 → 逐项执行 → 生成文件。这个过程有点像看一个员工在你面前列计划、动手干。

**③ 等它交付**：第一次任务大概几分钟。完成后，右侧结果区会出现这次任务的**产物**。

**④ 验收 + 迭代**：点开预览，看是不是你要的。不满意就直接在对话框里追加意见，比如"配色再深一点""标题字再大些"，它会接着改。**全程不需要你碰一行代码。**

我那次的实际用时：从输入需求到拿到第一版成品，**不到 10 分钟**，之后又改了两轮，一共 15 分钟收工。

## 顺手做两件事：领积分、签到

完成任务后，别急着关。登录后第一件事，其实是**领积分**——新用户一般有新手积分福利（几千积分、有有效期），每次任务会消耗积分。

入口一般在个人中心 / 使用量页面。另外每天可以**签到领积分**，连续签到有加成。

这是我踩过的坑：第一周我完全不知道有积分这回事，白亏了新手礼包。**注册后先领，别等过期。**

## 新手最容易翻车的 3 个坑

**坑 1：需求只有一个词。**
"做个页面""写个方案"——这种话交给任何 AI 都白搭。用三要素模板：要什么、给谁用、什么风格。

**坑 2：以为一句话就是全部，后面不能改了。**
恰恰相反，WorkBuddy 的对话是可以**持续追加**的。先交付一版，再一轮轮改，这才是正确姿势。别憋大招，一次把需求写到完美——你先写个 80 分的，它出个 80 分的，你再改到 95 分，比憋 5 分钟憋不出来强。

**坑 3：把敏感文件丢给它。**
任何云端 AI 工具都是这个提醒：商业机密、客户名单、私人聊天记录，别当附件传上去。用之前脑子里过一遍。

## 写在最后

第一次用 WorkBuddy，你只需要记住三件事：
1. **入口**：装桌面版，登录后把"工作空间"固定在一个文件夹（比如 `MyAI`）；
2. **界面**：左导航、中工作区、右对话面板；
3. **说话**：要什么 + 给谁用 + 什么风格。

这三件事跑通，你就完成了从"看着工具发呆"到"让 AI 干活"的跨越。剩下的一切——专家团怎么选、调研怎么做、网站怎么上——都是在"能开口提需求"这个基础上长出来的。
