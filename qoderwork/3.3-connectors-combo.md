## 写在前面

很多人在用了 QoderWork 两周之后，会遇到一个瓶颈：**"它什么都能做，但什么都不够深"。**

让它写文章，写得还行。让它做数据分析，也还行。但如果是一个律师、一个产品经理、一个电商运营——需要的不是"还行"，而是"专业"。

这就是 Skills、MCP 市场、专家套件存在的理由。这三样东西让 QoderWork 从一个"什么都知道一点的通才"，变成一个"懂行业的专才"。

## 第一层：Skills——AI 的"出厂技能表"

Skills 是 QoderWork 内置的能力模块。打开 Skills 面板（设置 → Skills），能看到当前加载了哪些技能。

默认技能包括：
- 文件读写（PDF / Word / Excel / Markdown）
- 网页解析（读取网页内容、提取关键信息）
- 数据分析（统计、排序、筛选、透视）
- 文本处理（翻译、润色、摘要、改写）
- 图片处理（OCR、格式转换）

**Skills 可以叠加。** 比如"读取 PDF + 提取关键信息 + 生成摘要 + 写入 Word 文档"——这是 4 个 Skills 的串行组合。

**Skills 可以分享。** v0.3.6 上线了技能分享——调试好的一套 Skills 组合，可以通过链接分享给同事。别人一键导入，直接获得技能配置。这就是"把经验沉淀为一套可复用的技能包"。

### docx/pptx 内置技能升级（v0.6.7）

写作工作台和幻灯片工作台的底层 Skills 在 v0.6.7 做了重大升级：
- **docx 技能**：支持更复杂的排版（多级标题、页眉页脚、分节符、目录自动生成）
- **pptx 技能**：支持图表联动（Excel 数据直接绑定到 PPT 图表）、母版编辑、智能配图
- **HTML 端内渲染**：生成的网页可以直接在 QoderWork 里预览，不需要导出到浏览器

这意味着以前需要手动到 Word/PowerPoint 里调整的细节，现在 AI 直接帮着做了。

## 第二层：MCP 市场——让 AI 接上外部世界

MCP（Model Context Protocol）是 QoderWork 与外部工具之间的标准接口。目前市场上已有 30+ MCP 插件。

### MCP 市场全景（截至 2026 年 8 月）

| 类别 | 连接器 | 核心能力 |
|------|--------|---------|
| **办公协同** | 企业微信、飞书、钉钉、Slack、MS365 Teams | IM 指令遥控 + 消息推送 |
| **文档知识** | 腾讯文档、飞书文档、语雀、Notion、OneDrive | 文档读写同步 |
| **商业数据** | 企百科⭐、1688 买家助手⭐、1688 商家助手⭐ | 企业信息查询、供应链数据 |
| **地图位置** | 高德云图⭐ | 位置搜索、路径规划、POI 查询 |
| **法律专业** | 华宇元典⭐、北大法宝⭐ | 法规检索、案例匹配、合规审查 |
| **开发工具** | GitHub、GitLab | 代码仓库操作 |
| **浏览器** | Playwright 浏览器 | 网页自动化 |

⭐ = v0.5.9 ~ v0.6.7 期间新增

### 重点连接器详解

**企百科连接器（v0.6.5新增）：**

这是对企业用户非常实用的一个连接器。装了之后，QoderWork 可以直接查询企业的工商注册信息、股权结构、诉讼记录、经营状况。

使用场景：
- 做竞品分析时："查一下这 5 家公司的注册资本和股东背景，做一张对比表"
- 做供应商审查时："查这家公司有没有法律诉讼记录"
- 做投资尽调时："梳理这家公司的融资历史和股权变更"

不需要手动去天眼查、企查查——AI 直接通过企百科 API 查询，几秒钟出结果。

**高德云图连接器（v0.5.9新增）：**

让 QoderWork 能"看懂地图"。装了之后可以：
- "查一下北京国贸 3 公里内有哪些宠物医院，按评分排序"
- "给我规划一条从西二旗到望京的路线，避开修路路段"
- "提取这个地址列表里所有门面店的经纬度坐标"

特别适合有线下业务需求的行业——零售、餐饮、物流、房产中介。

**华宇元典 + 北大法宝（v0.6.5新增）：**

法律专业人士的福音。这两个连接器让 QoderWork 能直接检索法律法规数据库：
- 华宇元典：智能案例匹配、裁判文书分析、类案推送
- 北大法宝：法规全文检索、法条沿革查询、关联法规推荐

律师让 QoderWork 查"跟这个案件类似的判例有哪些"——不再需要手动在数据库里搜半天。

**1688 买家/商家助手（v0.6.5新增）：**

- 买家助手：商品搜索比价、供应商筛选、采购建议
- 商家助手：店铺数据分析、竞品监控、客户管理

电商从业者可以直接在 QoderWork 里完成供应链研究和采购决策。

## 第三层：MCP Apps 协议——连接器的"下一代"（v0.6.5）

这是 MCP 生态的一个重要升级。

### 老版 MCP vs 新版 MCP Apps

| 维度 | 老版 MCP 连接器 | MCP Apps 协议 |
|------|---------------|-------------|
| 交互方式 | 纯文本指令 + 文本回复 | **交互式 UI + 结构化结果** |
| 结果展示 | 一段文字 | **卡片、表格、图表、按钮** |
| 操作流程 | 一次一个指令 | **多步骤交互式流程** |
| 用户体验 | 像命令行 | **像 App** |

### 举个例子

老版方式查企业信息：
> 你："查一下 XX 公司"  
> AI："XX 公司成立于 2018 年，注册资本 500 万，法人张三……"（一大段文字）

MCP Apps 方式查企业信息：
> 你："查一下 XX 公司"  
> AI：展示一张**企业信息卡片**——工商信息、股东结构、风险提示，每个字段有独立按钮可以展开详情。

看到的不是一大段文字，而是一个结构化的信息面板。这在处理复杂数据时体验差异巨大。

目前 MCP Apps 协议已支持企百科、高德云图、1688 等主流连接器。QoderWork 官方表示这只是开始——未来所有连接器都会迁移到 MCP Apps 协议。

## 第四层：专家套件——给 AI 装上一整套行业知识

Skills 是单点能力，MCP 是外部工具，而**专家套件是把一套 Skills + Prompt + 知识库 + MCP 打包成"这个行业的专属 AI"**。

### 当前专家套件全景（10+ 方向）

| 套件名称 | 适用人群 | 核心能力 |
|---------|---------|---------|
| 写作套件 | 自媒体人、内容编辑 | 选题→大纲→写稿→润色→排版 全流程 |
| 数据分析套件 | 运营、产品经理 | 数据清洗→分析→可视化→报告 |
| 项目管理套件 | PM、团队负责人 | 需求管理→任务拆解→进度追踪→周报 |
| 教学套件 | 讲师、培训师 | 课件生成→题库出题→作业批改→学情分析 |
| 技术导师套件⭐ | 程序员、技术新人 | 代码审查→技术方案评审→架构建议→学习路径 |
| 诉讼工具箱⭐ | 律师、法务 | 起诉状→证据清单→类案检索→法庭辩论策略 |
| 产品设计套件⭐ | UI/UX 设计师、产品经理 | 用户调研→需求文档→原型方案→设计规范 |
| 科技服务套件⭐ | IT 服务商、技术支持 | 故障诊断→解决方案→知识库→工单系统 |

⭐ = v0.5.9 ~ v0.6.5 期间新增

### 新套件详解

**技术导师套件：**

不只是"帮程序员写代码"——它提供一整套技术成长路径。给一段代码，它可以：审查代码质量、提出优化建议、对比不同的技术方案、推荐最佳实践。对技术新人来说，这相当于一个 24 小时在线的 senior 工程师 mentor。

**诉讼工具箱：**

整合了华宇元典和北大法宝两个法律 MCP 连接器。律师用这个套件，可以直接在对话中：分析案情→检索相关法条→查找类似判例→评估胜诉概率→起草起诉状初稿。不是"替代律师"，是"让律师省掉 70% 的搜索和文书工作"。

**产品设计套件：**

产品经理在做需求评审时最耗时的环节——竞品分析、用户调研报告、功能对比表——这些 AI 可以批量处理。设计套件配合设计工作台使用，能从"理解需求"一直做到"产出可交互的原型页面"。

**科技服务套件：**

IT 外包、软件服务公司、技术支持团队——这类角色最大痛点是"客户提了一个问题，得花半小时查文档"。科技服务套件把常见问题的解决方案沉淀为知识库，遇到问题时 AI 直接匹配答案。同时还能自动生成服务报告和工时统计。

### 专家套件分享链接（v0.6.5）

如果在一个领域里有自己的经验和方法论，可以基于官方套件做二次定制，然后生成分享链接。团队新成员加入时，不需要从头配置——点一个链接，导入全套"部门工作方式"。

## 怎么组合用：一个完整的例子

假设是一个**电商运营**，日常工作涉及：数据分析、竞品监控、供应链、文案写作。

可以这样配置：

1. **Skills 层**：加载数据分析 + 文本处理 + 网页解析
2. **MCP 层**：装 1688 买家助手 + 企百科 + 高德云图 + 企业微信连接器
3. **专家套件层**：装上数据分析套件 + 写作套件

实际使用场景：
- "查一下这周爆款的供应链数据"→ 1688 买家助手拉数据 → 数据分析套件出报告
- "帮我写一篇这个新品的推广文案"→ 企百科查产品公司背景 → 1688 对比竞品价格 → 写作套件出文案
- "给我下周要拜访的 5 家供应商做一份对比评估"→ 企百科查工商背景 → 1688 查采购数据 → 高德云图算交通距离 → 出综合评估表

**不是 AI 帮着做了一件事——是 AI 帮着协同了一整套工作流程。**
