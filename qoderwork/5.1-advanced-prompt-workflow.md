# 跟 QoderWork 说话的方式对了，效率翻 3 倍——Prompt、上下文窗口与工作流

> AI 不是智商不够——是每次都在从零教一个被格式化的实习生。用好 Prompt 记忆、上下文窗口管理、错峰模型调度和工作流，它才真正像个"专属的"助手。

> **更新说明（2026-08-07）：** 新增上下文窗口管理（1M/手动压缩）、模型三档选择与错峰策略。注意：Prompt 记忆是意识模式的前身——现在更推荐开启意识模式获得更好的跨会话记忆体验。

---

## 写在前面

用 QoderWork 超过两周的人会有一个共同的感受：**每天在跟它解释同样的背景信息。**

比如每次让它写公众号文案，都要说一遍"口语化、不说'在当今'、别用排比句、多举具体例子"——这些条件上周就说过了，但它不记得。

这不是它笨。是默认模式下的 AI 是无状态的——每次对话都是从头开始，不记得是谁、做什么、习惯什么风格。

解决这个问题的方法有两个：Prompt 记忆和工作流。这两个功能看起来不高调，但它们才是 QoderWork 从"通用 AI"变成"专属 AI"的关键。

---

## Prompt 记忆：让它记住你的习惯

在 QoderWork 设置 → 高级 → Prompt 记忆中，可以保存固定的背景信息。保存之后，每次发起新对话，这些信息会自动加载进去。

我保存了这些：

```
【我的身份】：
自媒体博主，主要写 AI 工具实操内容。目标读者是职场人和自由职业者——他们不想学技术，只想用 AI 提效。

【我的写作风格】：
- 口语化，用第二人称"你"
- 开头直接点出痛点，不要铺垫
- 不使用"在当今""随着……的不断发展""赋能"等 AI 味词汇
- 每个观点必须配一个具体场景或案例
- 段落短，不超过 4 行
- 结论要明确，不给模棱两可的建议

【我的禁忌】：
- 不要写排比句
- 不要用"综上所述"
- 不要给我定义和概念解释——我的读者不需要
- 结论部分不要写"总之""简而言之"
```

保存完之后，我每次用写作工作台写公众号内容，不需要再打 200 字的指令去约束风格。它自动按我的习惯来。

这种东西写一次、存进去、一直用。边际成本趋近于零。

## 工作流：把多步操作打包成一个按钮

比 Prompt 记忆更进阶的是工作流。它的本质是：**设计一套"指令→处理→输出"的流程，打包成一个按钮。以后点一次按钮就跑完全流程。**

举个例子：我做竞品分析的标准流程是——

1. 浏览器自动化：打开 3 个竞品官网，提取产品信息
2. 通用工作台：把提取的信息整理成对比表
3. 写作工作台：根据对比表生成分析报告

以前要分三次执行。现在我把这个流程做成一个工作流，按一次按钮全跑完。

怎么创建：在 QoderWork 的"工作流"页面，新建 → 添加节点 → 设置每个节点的指令和使用的 Agent → 串联顺序 → 保存。

建工作流需要花 10-20 分钟思考和调试。但建完之后，每次执行只需要 1 秒——点一下按钮等结果。

## 三个建议你立刻建的工作流

**工作流 1：每周项目检查**

```
节点1（通用工作台）: 扫描所有项目文件夹，列出本周修改的文件
节点2（通用工作台）: 对比上周，找出进度有偏差的项目
节点3（IM连接器）: 把检查结果推送到企业微信群
```

**工作流 2：文章多平台分发**

```
节点1（写作工作台）: 读取公众号原文
节点2（写作工作台）: 改写成小红书版本（1000字+emoji）
节点3（写作工作台）: 改写成知乎回答版本（深度+互动结尾）
节点4（写作工作台）: 改写成抖音口播（200字口语化）
节点5（文件存储）: 三个版本分别存到对应文件夹
```

**工作流 3：每日晚间归档**

```
节点1（通用工作台）: 扫描桌面和下载文件夹
节点2（通用工作台）: 识别今天新增的文件，按类型分类
节点3（通用工作台）: 把工作相关文件整理到项目文件夹
节点4（通用工作台）: 生成每日归档简报，存到「归档」文件夹
```

这些工作流建一个大概花 10-15 分钟。但未来每天省 20 分钟起步。

## Skills 套件：专家级别的 AI 能力包

Prompt 记忆是让 AI 了解你。Skills 套件是让 AI 学会新能力。

QoderWork Pro 内置了一套 Skills 套件——每个 Skill 是一个预训练的能力包，让 AI 在特定领域有专家级表现。比如：

| Skill | 能力 |
|-------|------|
| 数据分析师 | 读表格、算趋势、看相关性 |
| 文案优化师 | 写营销文案、改标题、做 A/B 测试 |
| 项目管家 | 做甘特图、排期、风险识别 |
| 数据采集器 | 爬网页数据、填表单、截图 |

每个 Skill 调用需要额外 Credits（10-50 Credits 不等），但效果比通用模式好一个档次。

比如"数据分析师"这个 Skill——之前我用通用工作台分析支出数据，AI 只能做基础的分类和汇总。启用了这个 Skill 之后，它能做同比分析、趋势预测、异常检测——输出质量高了一个等级。

**建议**：日常用通用模式，不要一直开着 Skills——烧积分。只有在任务比较重要、需要高质量输出的时候才开启对应的 Skill。

## 多 Agent 并行：多个工作台一起干活

QoderWork Pro 允许最多 3 个 Agent 同时并行干活。这是高级工作流的一个重要分支。

什么意思？可以同时：
- Agent 1 在写作工作台上写今天的文章
- Agent 2 在浏览器里采集竞品数据
- Agent 3 在设计工作台上做本周项目的一张信息图

三个 Agent 同时跑、互不影响。等它们全跑完——三条结果一起拿到。

适合什么场景？需要赶时间的场景——比如开会前 30 分钟要准备好所有材料。三个 Agent 同时干活，比一个挨一个跑节省 2/3 的时间。

但注意：三星并行会加倍消耗 Credits。不要把不需要并行的任务也拆成三个 Agent 跑——纯浪费积分。

## 上下文窗口管理：告别"说多了就忘"（v0.6.3 / v0.6.6）

这是 v0.6 系列的一个硬核升级。以前 QoderWork 的上下文窗口是固定的、有限的——长对话到了后面，AI 会"忘记"前面的内容。

从 v0.6.6 开始，上下文窗口支持手动设置，**最大可到 1M tokens**。

### 1M tokens 是什么概念？

- 一本 30 万字的中文长篇小说 ≈ 约 400K tokens → **可以整个喂进去做全文分析**
- 一个项目从立项到交付的所有文档 → **可以一次性加载，做全量交叉引用**
- 500 页的技术文档 → **可以同时放在上下文里，AI 帮找到任意两处之间的关联**

在此之前，处理长文档需要分段喂——看一段、分析一段。现在可以一次性全加载进去，AI 在全局视角下分析，质量完全不同。

### 手动压缩按钮（v0.6.3）

如果对话很长（比如改了十几轮文案），上下文窗口里的"历史消息"会占据大量空间。v0.6.3 增加了一个**手动压缩按钮**——一键把历史对话压缩成摘要，释放上下文空间。

不是自动压缩（怕不想要的时候被压缩丢了细节），而是需要手动点。这个设计是对的——上下文压缩是一个"有损"操作，应该由人来决定什么时候时机合适。

### 什么时候需要调整上下文窗口？

| 场景 | 建议窗口大小 |
|------|------------|
| 日常聊天、简单问答 | 默认（32K）足够 |
| 长文写作、反复修改 | 64K ~ 128K |
| 全文分析、多文档交叉对照 | 256K ~ 1M |

**注意：** 窗口越大，AI 处理越慢、积分消耗也越高。不是越大越好——够用就行。

## 模型选择与错峰策略：让积分花得最值的组合拳（v0.6.2 / v0.6.3）

前面 1.3 篇详细算过积分账，这里讲的是**怎么把模型选择和任务时间配得更聪明**。

### 三档模型，三个消耗档位

| 档位 | 积分 | 用在哪 |
|------|------|--------|
| 旗舰 MAX | 100% | 客户方案、公开发文、重要分析 |
| **高级**（v0.6.2 新增） | ~60% | 内部报告、日常分析、常规写作 |
| 标准 Turbo | ~25% | 分类整理、初筛总结、文件批量处理 |

### 错峰折扣：晚上用 MAX，积分打骨折

v0.6.3 上线了 Qwen3.7-Max 错峰折扣——在非高峰时段（主要是晚上和周末），MAX 模型积分消耗大幅降低。

我现在的策略是：
- 白天日常 → 高级档位
- 放在晚上跑的重要分析 → 错峰 MAX（质量最好、价格最低）
- 凌晨自动化 → Turbo（最便宜）

**同样的月积分池，用对了策略，实际产出能力提升 30-40%。**

设置路径：系统设置 → 模型管理 → 错峰调度 → 开启。

这里多说一句：错峰折扣不是"限时活动"，是 QoderWork 的调度策略。阿里云的算力在白天紧张、晚上有空闲——错峰就是把空闲时段拿出来打折用。这是可持续的机制，不用担心"活动结束就没有了"。

## 这一篇到这儿

高级玩法不是让学技术——是把"每次都要重复做的事"固化下来。

Prompt 记忆和工作流省掉每次的重复解释和执行。上下文窗口管理让在处理大任务时不被"遗忘"限制。模型三档+错峰策略让积分花得更聪明。

但真正让 AI 懂人的，不是手动写的 Prompt 记忆，而是意识模式（见 5.2 篇详细解读）。Prompt 记忆是手写给 AI 的规则清单——意识模式是 AI 自己观察、学来的。两者互补，一起用效果最好。

这五件事不复杂，也不需要技术背景。但 80% 的用户不会去用——因为他们从来不看"设置"页。如果这篇文章能让人花 20 分钟去配一次——后面的回报远超投入。
