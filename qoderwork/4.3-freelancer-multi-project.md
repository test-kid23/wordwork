# 一个人接 3 个客户、跑 5 个项目——自由职业者的 QoderWork 多线作战法

> 自由职业的核心瓶颈不是能力不够，是时间不够。QoderWork 不能帮你把一天变成 48 小时——但它能帮你把重复的事情自动化，把精力留给你真正该做的。v0.5.11 新增对话分组排序，v0.6.0 意识模式让不同项目拥有独立记忆。

## 写在前面

我做过两年自由职业者。那段时间最焦虑的不是"没有客户"——是"客户太多，忙不过来"。

同时跑 3 个项目的时候，每天的状态是这样的：上午帮客户 A 写方案，下午客户 B 打电话说需求变了，晚上客户 C 在群里催进度。脑子里同时挂着三根弦——每一根都不能断。

那段时间我靠三个东西活着：日历、Notion、咖啡。如果那时候有 QoderWork，Notion 可以不用了——AI 应该帮我管这些事，而不是让我在文档工具里手工整理。

## 多项目管理的基础设施

在讲具体工作流之前，先说一个前置工作：**你的项目文件命名和目录结构得规范。**

QoderWork 靠文件信息来检索和组织。如果你把所有客户的文件全堆在桌面上、命名乱七八糟——AI 没法帮你。

我的建议结构：

```
工作/
├── 客户A_XX项目/
│   ├── 合同/
│   ├── 方案/
│   ├── 交付物/
│   └── 沟通记录/
├── 客户B_XX项目/
│   ├── ...
└── 客户C_XX项目/
    └── ...
```

文件名格式：`日期_项目名_版本号.后缀`，比如 `240722_产品方案_v2.docx`。

这不是什么高级技巧——就是最基础的文件夹管理。但这是后面所有自动化能跑起来的前提。

## 场景一：每日工作启动

每天早上 9:00，我设的定时任务是：

> "扫描所有客户文件夹，检查以下信息：1. 各项目最近文件更新时间，超过 3 天没更新的项目标红。2. 各项目待办事项文件夹里的待办列表，今天到期的标黄。3. 汇总成一条早间简报。"

输出示例：

```
今日工作简报（7月28日）

【客户A - 产品方案】⚠️ 最后更新：3天前
  待办：方案第3章修改（今天到期）
  建议：今天优先处理

【客户B - 官网改版】✅ 正常推进
  昨天更新：首页布局 v3(7.27)

【客户C - 营销方案】🔴 最后更新：5天前
  待办：初稿提交（已超期2天）
  建议：今天必须联系客户确认需求变更
```

这份简报帮我三件事：
1. 知道今天该先干什么
2. 知道哪个客户被晾太久了（客户 C）
3. 知道哪些项目在平稳推进（客户 B），不需要加力

## 场景二：客户合同管理

自由职业者最容易被忽略但最要命的事——合同管理。

你签了 3 份合同、每份的付款节点不一样、有的按阶段有的按时间。如果漏了一个收款节点，相当于白干一个阶段。

QoderWork 能做的：

> "扫描「合同」文件夹下所有合同的 PDF 或 Word 文档，提取以下信息：1. 合同金额 2. 付款方式（一次性/分阶段）3. 各付款节点和条件 4. 已到期但未收款的节点。做成一张表格。"

你会得到一张看清所有合同收款状态的表格。哪个客户该打钱了、哪个阶段的款项到期了——一览无余。

然后你可以设置一个定时任务：

> "每个周一早上检查所有合同的付款节点，如果有本周内到期的收款节点，单独提醒我。"

这个不算高级功能——只是信息提取 + 定期提醒。但对自由职业者来说，意味着你不会在月底发现"原来上个月的款还没到"。

## 场景三：客户沟通记录自动归档

自由职业最烦的事：客户在三个不同的地方跟你沟通——微信说一点、邮件说一点、视频会上说一点。每次回过头来整理需求的时候，你忘了哪个需求是在哪里说的。

这部分 QoderWork 不能完全自动化——因为你的微信聊天记录它读不了（除非通过企业微信连接器）。但它能做的是：

**对于邮件沟通：**

> "总结本周所有跟客户相关的邮件沟通要点，按客户和项目分类。特别标记：需求变更、时间调整、预算变化——这三类信息。"

**对于会议记录：**

如果你有会议录音（用飞书妙记/通义听悟等工具转文字），把文字版丢进 QoderWork：

> "把这段会议记录整理成 3 点：1. 客户确认了什么 2. 客户要求改什么 3. 下一步你需要做什么。"

然后把整理结果保存到对应客户的「沟通记录」文件夹。

每周结束的时候，每个客户都有一个自动更新的沟通日志。发生争议的时候——"我们明明说的是 XX 号交付"——翻出日志就能核实。

## 场景四：客户报价方案快速生成

自由设计师、自由文案、自由咨询师——报价是高频需求。

你可以这样做：

> "根据「客户A_项目需求」文件夹里的需求文档，生成一份 3 档报价方案——基础版、标准版、尊享版。每档说明服务范围、交付物清单、时间周期。参考我保存在「模板」文件夹里的报价模板格式。"

AI 会基于需求文档推测不同档次的服务范围——这些推测可能不完全精准——但至少给你一个 70% 能用的初稿。省掉的是排版和基础措辞的时间。
