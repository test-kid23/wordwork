幻灯片工作台实战

一句话生成 PPT 这个功能，宣传很唬人，实际用起来翻车率 50%。原因不在 AI——在喂进去的信息量。

📝 写在前面：QoderWork 幻灯片工作台的宣传语是"一句话生成完整 PPT"。我信了。我说了一句："帮我做一个 Q4 季度工作汇报的 PPT。"它生成了 12 页，每页一个标题加两段空话。我把这个 PPT 发给一个做设计的朋友看，她回了两个字：垃圾。我差点把这个工作台判死刑。但后来我换了种用法，结果完全不一样了。所以这一篇不是要说"幻灯片工作台很厉害"，而是要说"什么情况下它厉害，什么情况下它是智商税"。

1它到底是怎么做 PPT 的

在讲好用的用法之前，得说清楚它背后的机制。因为理解了机制，才知道怎么喂它信息。

QoderWork 做 PPT 不是"套模板填充"。它是多 Agent 协作：

1. 一个 Agent 负责理解需求，拆成 PPT 结构
2. 一个 Agent 负责写大纲——每一页说什么
3. 一个 Agent 负责写正文——把大纲扩充成具体内容
4. 一个 Agent 负责配色方案——背景色、字体色、强调色
5. 一个 Agent 负责配图——选择合适的插图/图标
6. 一个 Agent 负责排版——文字和图片在页面上的位置
7. 一个 Agent 负责演讲备注——每页自动生成 150-300 字的口语化备注
8. 还有几个 Agent 负责润色、校对、一致性检查

总共 11 个 Agent 并行干活，在后台同时跑。所以一句话下去，它要等 3-5 分钟才出结果——因为不是一个人在干活。

❌ 这个架构听起来很唬人。但问题也在这里：11 个 Agent 每人拿到的信息，只有输入的那一句话。
❌ 输入"帮我做一个产品介绍的 PPT"——大纲 Agent 不知道产品是什么、卖给谁、跟竞品有什么区别。配图 Agent 不知道行业是什么，只能找通用商务插画。正文 Agent 不知道想强调什么，只能写万金油式描述。
✅ 所以出来的是垃圾。不是 Agent 不行——是它们饿着肚子干活，只给了它们一粒米。

━━━━━━━━━━━━━━

2怎么让它产出一个像样的 PPT

后来我换了种方式。不再一句话丢给它，而是先把所有材料喂进去。

📌 第 1 步：把产品介绍文档直接丢进去

我有一份产品介绍 Word 文档，差不多 2000 字——产品定位、核心功能、目标用户、竞品对比、定价策略。我直接复制粘贴进对话框，说：

"根据这份产品介绍文档，帮我做一个面向投资人的产品介绍 PPT，12 页以内。重点是讲清楚市场机会、差异化优势、以及为什么能做起来。不要空洞的行业数据——用文档里已有的信息。"

这一次，它先展示了一个大纲让我确认：

1. 封面：产品名+一句话定位
2. 市场机会：这个赛道为什么值得做
3. 用户痛点：目标用户在经历什么
4. 产品方案：我们怎么解决
5. 核心功能：3 个关键差异化能力
6. 竞品对比：我们 vs 竞品的一页对比
7. 商业模式：怎么赚钱
8. 团队背景：为什么我们这队人能做
9. 增长数据：目前的 traction
10. 融资计划：融多少、花在哪
11. 联系方式
12. 感谢页

大纲是对的。因为它从文档里提取了信息，知道要讲什么。

📌 第 2 步：调整大纲

我说"把竞品对比放到核心功能前面——先讲为什么我们不一样，再讲我们有什么"。它改了。然后我说"商业模式跟增长数据合成一页，太占篇幅了"，它也改了。

📌 第 3 步：确认后开始生成

这次等了 4 分钟。出来的结果跟第一次完全不是一个级别的：

✅ 每一页的内容有具体信息，不是空话
✅ 竞品对比页里有真实的差异化点
✅ 演讲备注里写了 200 字的口语化介绍——连"这页讲到这儿可以停顿一下让投资人消化"这种提示都有

💡 前后对比：

一句话版：12 页，每页 2-3 句空话，费时 3 分钟，可用度 20%
喂文档版：11 页，内容具体有逻辑，费时 20 分钟（含来回改大纲），可用度 75%

如果你想要 90 分以上的 PPT——还得自己手动调几页。但相比从零做起，省了至少 2 小时。

3演讲备注——一个被低估的加分项

特别说一下演讲备注这个功能。

每页 PPT 生成的时候，它自动附带 150-300 字的备注。不是那种"这一页讲了 XXX 方面的内容"的废话备注，而是口语化的、可以直接拿来照着说的备注。

比如产品对比那一页的备注：

"好，接下来我们看一下跟竞品的对比。左边是我们的产品，右边是目前市面上的主流方案。大家注意看第三行——这个是我们的核心差异点。友商的做法是……，这意味着用户的成本会……，而我们的方案是……。所以在实际落地的时候，客户通常会在用了一个月之后发现这个问题，然后转过来找我们。"

这个备注让你在演讲的时候有一个自然的话术框架。不是念稿——是有一个"这页该说什么"的参考。当然，它不知道你实际的销售话术是什么，所以细节还是得自己改。但 80% 的框架是能用的。

4什么地方绝对别用幻灯片工作台

① 高度依赖视觉设计的场合
如果你的 PPT 是去参加设计大赛、品牌发布会、或者是面向 C 端的营销物料——别用。它的设计能力是"不出错"级别，不是"出彩"级别。配色克制但平淡，排版规范但无趣。

② 信息量极少的场景
如果你连自己产品的核心卖点都说不清楚——AI 也不知道。它不会替你发明信息。你喂什么它用什么，没喂的就只能靠通用内容填充。

③ 需要原创插画/图表的 PPT
它的配图库比较有限，大部分是通用商务风格。如果你需要定制化的数据可视化、手绘插画、品牌专属视觉——得自己去其他地方做图然后插入。

5模板复用：做一次，下次直接用

对一个经常做 PPT 的人来说，幻灯片工作台还有一个好用功能：模板固化。

你做出来一版满意的 PPT——封面风格、配色方案、页眉页脚、字体搭配——可以保存为模板。下次做新 PPT 的时候，选这个模板，它自动延续你的风格。

我给自己固化了两个模板：

✅ 对外提案版——稍微正式一点，给客户看的

✅ 内部汇报版——更简洁，给老板/同事看的

第二次做 PPT 的时候不再需要从头调风格，直接选模板+喂内容就行了。时间从 20 分钟缩到 10 分钟。

这一篇到这儿

幻灯片工作台不是"一句话生成神级 PPT"的魔法工具。它是一台榨汁机——你放一个橙子进去，它给你一杯橙汁。你放一粒米进去，它给你一碗米汤。

喂的信息越多、越具体，出来的东西越好。这一点不止适用于 PPT——后面要讲的通用工作台、设计工作台，都遵循同样的规律。
