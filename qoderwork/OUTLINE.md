# QoderWork 系列创作大纲

> 阿里云推出的桌面 AI 智能体工作台，Qoder CN 产品家族中面向非技术用户的办公助手。面向公众号读者的深度内容规划。

---

## 整体定位

**QoderWork 不是你打开来聊天的 AI 工具，而是一个能直接操控你电脑帮干活的桌面智能体。**

它跟 Qoder（程序员用的）共享同一套阿里云账号和 Credits 体系，但完全是两条产品线：
- Qoder：嵌在 IDE 里，帮程序员写代码、改 Bug、做架构
- QoderWork：独立桌面客户端，帮打工人写周报、做 PPT、操作网页、定时执行任务

为什么值得单独开一个系列？因为 wordwork 的核心读者——职场人、自由职业者、自媒体博主、小型创业者——绝大部分不是程序员，但每天都在跟文档、表格、PPT、网页操作、重复性任务搏斗。QoderWork 恰好是给他们用的。

把它想成"坐在你电脑上的 AI 实习生"：你告诉它干什么，它自己拆步骤、操作浏览器、读写本地文件、产出结果。不需要你会写代码。

## 第一部分：入门认识系列

### 1.1 QoderWork 是什么？——阿里搞了个能帮你干活的桌面 AI

- 前世今生：通义灵码 → Qoder CN 品牌升级 → QoderWork CN 独立产品线
- 不是"又一个 AI 聊天窗口"：它会操作你的浏览器、读写你的文件、定时自动干活
- 跟 Qoder 的关系：同一账号、共享 Credits，但 QoderWork 给非程序员用
- 核心能力一句话版：写作→做PPT→设计网页→操控浏览器→定时任务→手机远程指挥
- 谁适合用？写周报写到吐的、要做PPT但不会设计的、每天重复操作网页的、想做自媒体但卡在产出效率的
- 谁不适合用？写代码的（用 Qoder）、已经有成熟工作流不觉得累的

### 1.2 安装与第一条指令——比装个微信还简单

- 去哪下载：阿里云官网搜 QoderWork CN，Mac/Win 都有
- 登录方式：阿里云账号（手机号/微信/支付宝都可以）
- 第一印象：界面长什么样，跟微信/钉钉有什么区别
- 第一条指令："帮我整理一下桌面，把最近 7 天的文档按类型分类到不同文件夹"
- 看它是怎么拆步骤的：理解指令→扫描桌面→新建文件夹→移动文件→汇报结果
- 跟打开一个 AI 网页对话的本质区别

### 1.3 社区版 vs Pro 版——到底要不要花钱

- 社区版（免费）：基础对话、简易内容创作、限时 Pro 体验
- Pro 版（付费）：2000 Credits/月，解锁全部工作台、浏览器自动化、定时任务、IM 联动
- 新用户福利：注册送积分 + 邀请送积分（就是我们之前写的那篇 aishare-014）
- 学生/教师认证额外送 4000 积分
- 我的判断：如果你是轻度用户（偶尔让它写写东西）→社区版够用；如果你把它当办公主力→Pro 59 元/月值不值？取决于你用它省了多少时间
- 一个省钱思路：夜间模型自动切换，Credits 消耗打两折，批量任务晚上跑

## 第二部分：四大工作台深度系列

### 2.1 写作工作台——从一句话到一篇长文

- 界面布局：左右分栏，左边提需求，右边实时生成
- 跟通用 AI 聊天的区别：框选文字就能润色/改写/翻译/扩展，不用反复复制粘贴
- 实战："帮我写一篇关于远程办公效率的公众号文章"→看它怎么拆结构→逐段生成→你边看边调
- 局部调整：选中一段→"这段太正式了，改口语化一点"→实时对比
- 多语言翻译：丢一篇英文文章进去→逐段对照翻译
- 不推荐场景：高度个人化的内容（个人经历、观点输出）还是自己写，QoderWork 最多帮你润色
- 跟公众号写作的配合：可以用它生成初稿框架，但人味和立场必须自己加

### 2.2 幻灯片工作台——11 个 Agent 同时给你做 PPT

- 不是套模板，是多 Agent 协作：一个管大纲、一个管配色、一个管配图、一个管正文、一个管备注……
- 输入一句"帮我做一个关于 Q4 季度工作汇报的 PPT"→自动拆成 11 个阶段并行
- 内置 30+ 模板风格，每页独立 HTML 存储
- 生成后自动附带 150~300 字演讲备注——这个太实用了
- 导出格式：PDF / HTML / PPTX 三种
- 满意版本可抽取为团队模板，下次直接复用
- 实测风险：生成质量取决于你给的信息量，一句标题出不来好 PPT
- 跟传统做 PPT 方式的对比：以前是找模板→填内容→调格式→找配图→写备注，5 个步骤压缩成一句话

### 2.3 设计工作台——不会画图也能出专业页面

- 核心思路：Code as Design——不是生成 PNG 图片，而是生成可编辑的网页预览
- 内置 100+ 视觉风格模板（科技感、极简、商务、新中式……）
- 实战："帮我设计一个宠物寄养平台的首页"→出完整前端代码→所见即所得预览
- 一键推送到 Qoder IDE 继续开发（如果后期需要程序员介入）
- 无限画布编辑 + 暗黑模式切换
- 适合做什么：产品原型、活动落地页、个人主页、品牌介绍页
- 不适合做什么：插画、海报、复杂视觉设计（那得找专业设计师）
- 自由职业者/小型创业者的零成本产品展示方案

### 2.4 通用工作台——什么都能干的万金油

- 没有固定模板，自然语言描述任务，自动拆解成多步骤执行
- 适合场景：行业调研、本地文件整理、数据统计分析、简历筛选、竞品分析
- "帮我把这个 Excel 里 2025 年的销售额按月汇总，做一个趋势分析"
- "帮我在 downloads 文件夹里找出所有 PDF 合同，提取关键条款做一张对比表"
- "帮我分析这 50 份简历，按岗位匹配度排名，标记需要面试的人"
- 通用工作台的边界在哪——什么时候该切换到专业工作台？

## 第三部分：自动化与连接器系列

### 3.1 浏览器操控——AI 替你在网页上点点点

- Chrome 连接器：以扩展形式安装，自动继承浏览器登录状态
- 这意味着什么？你登录了小红书、知乎、B 站、钉钉，QoderWork 也能操作这些页面
- 接力按钮：把当前标签页内容一键推给 QoderWork 解析
- 实战一：竞品调研——"帮我去京东搜 5 个扫地机器人品牌，对比价格和评价，做一张表"
- 实战二：数据采集——"帮我把这个网页上的表格数据提取出来，导出成 Excel"
- 实战三：批量操作——"帮我在钉钉后台把本周请假的人都标记出来"
- 安全提示：别让它自动操作支付页面、别给敏感账号权限
- 多标签页同时操作 + 任务归档释放上下文

### 3.2 定时任务——设好一次，以后不用管

- 六种触发频率：单次、固定间隔、每小时、每天、每周、每月
- 不需要 crontab 表达式，用自然语言"每天下午 6 点整理下载文件夹"
- 实战一：每天自动抓取竞品公众号更新→汇总成简报
- 实战二：每周一自动生成上周工作总结→发到钉钉群
- 实战三：每月 1 号自动整理财务数据→生成月度报表
- 注意事项：
  - 电脑不能休眠/合盖，笔记本用户要开"防止系统休眠"
  - WiFi 断了任务就停了，重要任务要有通知机制
  - 每次触发产生独立对话记录，可回溯
- 可以调用 Skill、连接器、读写本地文件→定时任务 + 浏览器自动化 = 真正无人值守

### 3.3 Skills 与专家套件——把重复活儿变成一键执行

- Skill 就是一个自然语言写的工作规范：触发条件→执行步骤→注意事项
- 本地保存在 `~/.qoderworkcn/skills/`，就是一个 Markdown 文件
- 完全兼容 Claude Code Skills！可以直接迁移
- 技能市场：文档处理、数据分析、图像编辑……下载即用
- 意识系统：检测到你反复做同一类任务→主动建议固化 Skill
- 专家套件：预置工作流，首批 10 个方向——产品管理、企业法务、财税、投研、市场营销……
- 产品管理套件实测：内置 28 条命令，从需求框定到 PRD 输出全流程
- 一个让我不想用的瞬间：意识系统偶尔自作主张固化错的东西

## 第四部分：实战场景系列

### 4.1 职场人必备：周报、邮件、会议纪要一键搞定

- 场景一：周报——"帮我总结本周的微信聊天记录、邮件和本地文档，生成周报"
- 场景二：会议纪要——"帮我整理这 45 分钟录音的文字稿，提取关键决策和待办事项"
- 场景三：商务邮件——"帮我根据这个客户反馈写一封正式的回复邮件，语气专业但不生硬"
- 场景四：数据汇报——"帮我把销售数据做成一张直观的图表，附带一句话总结"
- 职场人最容易掉的坑：直接用 AI 生成的内容不改就发出去
- 正确姿势：AI 出框架→你补细节→AI 润色→你再过一遍

### 4.2 自媒体博主：公众号、小红书内容创作流水线

- 这个跟 wordwork 的读者直接相关
- 场景一：选题+大纲——"帮我根据最近一周的数据热点，出 5 个公众号选题，每个附 3 点大纲"
- 场景二：初稿生成——写作工作台出文章框架，自己注入人味和立场
- 场景三：小红书配图——用设计工作台生成卡片式配图，风格统一
- 场景四：多平台分发——一篇文章改写成公众号版、小红书版、知乎版
- 重点提醒：QoderWork 能帮你提效 70%，但最后 30% 的"人味"必须你自己来——这是我们的写作规矩
- 跟纯手工创作的对比：以前写一篇公众号 4 小时，现在 1.5 小时

### 4.3 自由职业者：提案、报价、项目管理一条龙

- 场景一：客户提案——"帮我根据这个需求简述，写一份专业的项目提案，含方案、排期、报价"
- 场景二：报价计算——"分析我这个月的时间记录，算一下每个客户的实际时薪"
- 场景三：项目进度汇报——定时任务每周五自动推送项目进度给客户
- 场景四：发票和合同——读取本地合同模板→自动填入客户信息→生成待发版本
- 自由职业者的核心痛点：一个人干全栈的活，QoderWork 帮你把非核心工作自动化
- 一个很现实的省钱账：Pro 版 59 元/月 vs 雇一个兼职助理 2000 元/月

### 4.4 小型创业者：市场调研、财务分析、竞品监控

- 场景一：市场调研——浏览器自动化扫行业报告→提取关键数据→生成分析报告
- 场景二：竞品监控——定时任务每天爬竞品官网+公众号→推送到企业微信
- 场景三：财务分析——丢 Excel/CSV 进去→自动分类、趋势分析、异常标记
- 场景四：招聘辅助——简历筛选→匹配度打分→生成面试问题清单
- 小型创业者的 AI 使用误区：把 AI 当军师（危险）vs 把 AI 当助理（正确）
- QoderWork 在这个场景的最大价值：把"必须做但不想做"的事自动化

## 第五部分：高级玩法系列

### 5.1 IM 频道——用微信、钉钉远程指挥你电脑干活

- 支持五大平台：钉钉、飞书、Lark、微信、企业微信
- 绑定后在手机上 @机器人 →桌面端 QoderWork 自动执行→结果推回聊天窗口
- "查下明天天气，在电脑上设 7 点闹钟"
- "帮我在电脑上把最新的项目文档发到群里"
- "帮我看一下电脑上的 QQ 邮箱，有没有张三的回复"
- 安全边界在哪：什么指令不该在 IM 频道里发？
- 实际体验：比我想象的好用，但微信机器人体验不如钉钉

### 5.2 应用快照 + 意识系统——越用越懂你的工作习惯

- 应用快照：连按两次 Command→自动截取当前窗口→作为上下文发送
  - "帮我分析这张图里的数据表格"
  - "这段报错是什么意思，帮我查一下"
- 意识系统：
  - 短期记忆：当前对话上下文
  - 长期记忆：以 Markdown 存本地，可编辑
  - 技能进化：检测重复模式→建议固化 Skill→采纳/驳回
- 这是 QoderWork 跟一次性 AI 对话的最大差异——它不是每次聊天都从零开始
- 隐私提醒：所有记忆存本地，你可以随时查看和删除

### 5.3 多模型切换 + 夜间省钱模式

- 支持模型池：Qwen 全系、DeepSeek、GLM、Kimi、MiniMax
- 什么时候该切模型：写作→Kimi（长文本强）、推理→DeepSeek、中文办公→Qwen3.7MAX
- 夜间模式：自动切换便宜模型，Credits 消耗打两折
- 省钱策略：白天复杂任务用 Qwen3.7MAX，晚上批量任务切便宜模型
- 各模型在 QoderWork 里的实际表现 vs 原生 API 的差距

## 第六部分：对比与踩坑系列

### 6.1 QoderWork vs 通用 AI 聊天工具——根本不是一个物种

- vs 文心一言/豆包/通义千问网页版：那些是"聊天"，QoderWork 是"执行"
- vs Notion AI：Notion AI 嵌在文档里，QoderWork 跨应用操作
- vs 钉钉 AI 助理：钉钉 AI 偏协作流程，QoderWork 偏个人生产力
- 最根本的区别：通用 AI 告诉你"应该怎么做"，QoderWork 直接帮你做
- 一句话版：网页 AI 给你答案，QoderWork 帮你干活

### 6.2 这些情况提前知道——QoderWork 常见问题与注意事项

- 电脑休眠 → 定时任务停摆 → 怎么设"防止休眠"
- 浏览器自动化偶尔卡住 → 页面加载慢/AJAX 异步加载导致 → 怎么加等待
- 生成内容"AI 味太浓" → 怎么调提示词让输出更自然
- PPT 生成质量忽高忽低 → 输入信息的丰富度直接决定输出质量
- 技能市场的第三方 Skill 质量参差不齐 → 怎么鉴别
- 意识系统"自作主张"固化错的 → 怎么驳回和清理
- Mac vs Windows 的体验差异 → Win 版某些功能体验不如 Mac

### 6.3 Credits 精算——怎么用最少的积分办最多的事

- Credits 消耗机制：不同任务、不同模型的消耗差异
- 一个典型月账单（真实数据）：轻度用户 vs 重度用户
- 省钱五大招：
  1. 简单任务用社区版模型
  2. 夜间批量跑便宜模型
  3. 学生/教师认证拿 4000 额外积分
  4. 邀请好友各得 200 积分
  5. Skill 固化后重复任务不再浪费上下文
- 什么时候从社区版升 Pro：当你发现每个月都想用这些功能但社区版不够的时候
- 一个省钱但不推荐的方案：注册多个号轮流薅新用户福利

## 写作风格约束

参照项目 `PROJECT_CONTEXT.md` 中的「写作风格指引」：

- **减少 AI 味道**：不用三段式排比、不写教科书结构、结尾禁止升华金句
- **加入人味**：有立场不端水、有真实使用经历、口语化转折词
- **有"不推荐"板块**：每篇至少有一处告诉读者"这个场景别这么用"
- **留白**：不必每个概念都填满
- **实用优先**：像同事教同事，每一步说清楚"为什么这么做"
