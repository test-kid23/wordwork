# AI 测试技术分享 · CSDN 内容规划

> 基于 VIP-AI 全栈测试专家课程的三条主线：API 自动化 + Web 自动化 + 平台开发
> 每条主线拆分为 5-11 期深度长文，共 26+ 期

---

## 三条主线的定位与关系

```
主线一：API 自动化（测试工程师）
  │  requests + pytest + 鉴权 + Mock + AI 断言
  │
主线二：Web 自动化（测试工程师）
  │  Playwright + Page Object + Agent + 视觉方案
  │
主线三：平台开发（架构师/平台工程师）← 新增
  │  工具链开发 + AIQE 平台搭建 + Agent 中心 + 流程编排
  │
  └──── 主线一、二的工具能力 → 封装为可复用 CLI → 接入主线三平台
```

## 主线一：AI 辅助接口自动化测试（5 期）

### 第1期：requests 核心编程与 AI 协作实践 ✅
- requests 完整执行链路详解
- Session 管理与连接复用
- AI 辅助生成与审核代码
- 从 curl 到 requests 的自动化转换

### 第2期：从脚本到 pytest 工程化演进
- pytest fixture 设计模式
- conftest.py 分层架构
- 参数化测试与数据驱动
- AI 辅助重构与 diff 审核

### 第3期：鉴权、签名与数据加解密实战
- Token/Bearer/Cookie-Session 鉴权链
- API Key + HMAC 签名机制
- MD5/SHA/RSA/AES 加解密处理
- 时间戳防重放攻击

### 第4期：Mock、依赖注入与异常场景设计
- unittest.mock/pytest-mock 深度使用
- 外部服务模拟与契约测试
- 异常场景穷举：超时、500、数据异常
- 测试数据工厂模式

### 第5期：代码调用 AI 接口与智能断言
- OpenAI/Claude API 集成
- Prompt 工程：让 AI 判断业务正确性
- Token 成本控制与缓存策略
- AI 断言 vs 传统断言的边界

## 主线二：AI 辅助 Web 自动化测试（5 期）

### 第6期：Playwright 核心编程与 AI 协作 ✅
- 最小浏览器自动化链路
- AI 辅助生成并审核 Locator
- 从"能操作"到"能验证"

### 第7期：Page Object 模式与测试框架设计
- Page Object 从零到一
- 组件化封装：导航栏、表单、弹窗
- 浏览器生命周期管理
- pytest + Playwright 集成

### 第8期：元素定位策略深度对比
- CSS/XPath/role/text 定位对比
- 稳定定位的黄金法则
- 视觉模型辅助定位原理
- 混合定位框架设计

### 第9期：DOM Agent vs 视觉 Agent 技术选型
- Playwright CLI Agent 深度使用
- Midscene.js 纯视觉方案
- Agent 的可靠性边界与兜底
- 三类路径（脚本/DOM/视觉）的协作策略

### 第10期：失败诊断与 AI 辅助修复 ✅
- Web/API 测试失败分类体系
- 证据链收集：日志+截图+录屏
- AI 辅助根因定位 Prompt 设计
