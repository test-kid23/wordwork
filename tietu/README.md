# 贴图系列 · 一图讲清（WeChat Pictorial）

> 定位：**用一张图讲清一件事**——面向微信公众号的图片化科普内容。跨系列取材，把项目里最值得讲清的工具、大模型、参数，做成"一图看完就懂"的贴图。
> 平台：**微信公众号为主**（图片消息 / 图文贴图），不发小红书。
> 内容方向：**工具科普 · 大模型对比介绍 · 参数解读**。

---

## 这是什么

主系列（`workbuddy/`、`codebuddy/`、`qoder/`、`deepseek/`、`rag/` 等）产出的是**深度长文**；`tietu/` 产出的是**公众号里的图片化科普**。

同一份知识，两种吃法：
- 长文：讲透来龙去脉、给完整方法（主系列）
- 贴图：一图一个结论，扫一眼就懂（本目录）

两者互相导流：贴图末尾挂长文，长文里配贴图速查卡。

## 三大内容方向

| 方向 | 讲什么 | 示例 |
|------|--------|------|
| 🔧 **工具科普** | 一个工具是什么、能干什么、和同类差在哪 | 一图科普 CodeBuddy 能干什么 |
| ⚔️ **大模型对比介绍** | A vs B 横评，各适合谁 | 一图对比国产大模型：混元 / DeepSeek / 通义 / GLM |
| 📊 **参数介绍** | 大模型的关键参数怎么看 | 一图看懂上下文长度 / 参数量 / 推理能力 |

## 三种内容形式

| 形式 | 张数 | 适用场景 |
|------|------|---------|
| **一图详解** | 1 张 | 单个工具 / 概念 / 参数讲透 |
| **一图对比** | 1 张（或 2 拼） | A vs B 横评 |
| **多图系列** | 3–9 张 | 一个主题拆解连载 |

## 目录结构

```
tietu/
├── README.md            # 本文件
├── OUTLINE.md           # 系列大纲（选题池 / 制作规范 / 发布策略）
├── templates/           # 图卡 HTML 模板（按公众号尺寸出图）
├── published/           # 已发布成品（HTML + PNG）
└── image/               # 用到的截图 / 素材
```

## 工作流

1. **选题** → 从 `OUTLINE.md` 的选题池里挑，或从主系列长文里抽"最值得一图讲清"的点
2. **写图卡** → 一个 HTML 出一张图（公众号尺寸，配色见 `wx_format_guide.md`）
3. **出图** → 浏览器截图 / 导出 PNG，命名遵循规范
4. **发布** → 微信公众号（图片消息 / 图文贴图）；文末挂对应长文引流
5. **归档** → 成品进 `published/`，状态回写 `OUTLINE.md`

## 命名规范

`wx-{形式}-{编号}-{主题}.png`

- 形式：`onepic`（一图详解）/ `vs`（对比）/ `series`（多图）
- 示例：`wx-onepic-01-workbuddy.png`、`wx-vs-01-workbuddy-vs-codebuddy.png`、`wx-series-01-llm-params.png`

## 相关规范文件

| 文件 | 用途 |
|------|------|
| `../wx_format_guide.md` | **公众号排版规范（做图/发布必读）**：配色、图片宽度、封面尺寸 |
| `../csdn_format_guide.md` | 若贴图对应的是 CSDN 深度长文，引流文案参考 |

> 配色：公众号统一走 `wx_format_guide.md` 的蓝 + 紫 + 中性灰体系，全图主色不超过 3 个。**本系列不发小红书，不适用 xhs 卡片配色方案。**

## 快速开始

1. 打开 `OUTLINE.md` 看首批选题池
2. 挑一个选题，在 `templates/` 里挑最接近的卡片模板
3. 按 `wx_format_guide.md` 配色与尺寸出图
4. 成品进 `published/`，状态回写大纲
