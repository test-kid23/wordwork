## 0. 定位与差异化

**是什么**：把主系列（workbuddy / codebuddy / qoder / qwenwork / deepseek / rag / claude_code / AIshare / opc）里最值得讲清的内容，浓缩成"一图一个结论"的公众号贴图。

**和主系列的关系**：

| | 主系列长文 | 本系列贴图 |
|---|---|---|
| 载体 | 长文（1500–5000 字） | 图（1 张 or 3–9 张） |
| 吃法 | 讲透来龙去脉 | 扫一眼得结论 |
| 作用 | 建立信任、深度留存 | 拉新、速查、最大化转发 |
| 关系 | 贴图末尾挂长文 | 长文里配贴图速查卡 |

**差异化铁律**：
1. **一图一结论**——不是截图堆砌，图上必须有一句"看完得到什么"
2. **真实优先**——工具界面用真实截图；模型/参数类用权威数据（标明来源），不编数字
3. **可独立成篇**——单张图脱离上下文也能看懂，方便被单独转发
4. **通俗不糊弄**——科普面向非技术读者，但数据要准、术语要解释

## 6. 制作规范

### 6.1 尺寸（微信公众号）

| 用途 | 建议 | 备注 |
|------|------|------|
| 公众号封面（首图） | 2.35:1（约 900×383） | 与标题钩子搭配 |
| 正文贴图 / 信息图 | 宽度 1080px，高度不限（竖长图） | 适配手机阅读 |
| 图片消息内图 | 1:1 或 3:4 | **发布前核对公众号后台当前要求** |

> 图片宽度不得低于 677px（微信正文宽度），详见 `../wx_format_guide.md` 第七章。

### 6.2 配色

- 统一走 `../wx_format_guide.md` 的 **蓝 `#4A90D9` + 紫 `#8e44ad` + 中性灰** 体系；
- 全图主色不超过 3 个，对比类可用蓝/紫区分两栏；
- **本系列不发小红书，不套用 xhs 卡片配色方案。**

### 6.3 内容与排版

- 一张图 = 一个结论；标题 15–25 字，套"数字 + 痛点/好奇 + 结论"公式；
- 要点 ≤ 5 条，每条一行、可扫读；
- 工具科普：真实界面截图做证据；**模型对比 / 参数解读：数据必须标来源、标采集时间，不编数字**；
- 底部统一留「系列标识 + 来源长文」导流位。

### 6.4 制作流程

```
选题 → 挑模板（templates/）→ 写图卡 HTML（公众号尺寸）→ 出图（PNG）
     → 命名归档（published/）→ 发布 → 回写本大纲状态
```

## 7. 发布与导流策略（微信公众号）

| 形式 | 用途 | 引流 |
|------|------|------|
| 图片消息 / 贴图 | 以图为主的科普单发 | 图片末尾 / 第一句挂长文钩子 |
| 图文内插贴图 | 长文里的速查卡 | 长文正文直接引用贴图 |
| 合集 | 把同主题贴图收进公众号合集 | 微信会推合集，形成常驻入口 |

**导流闭环**：贴图 → 长文（文末钩子），长文 → 贴图（速查卡），浅内容拉新、深内容留存。

**发布节奏**：配合主系列更新节奏；蹭新工具 / 新模型热度时可提速单发。

- `onepic-tool.html`——一图详解工具
